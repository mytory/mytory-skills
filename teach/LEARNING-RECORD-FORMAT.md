# 학습 기록 형식

학습 기록은 `./learning-records/`에 위치하며 순차적 번호: `0001-slug.md`, `0002-slug.md` 등. 첫 번째 기록이 작성될 때만 디렉터리를 게으르게 생성.

ADR의 교육적 동등물: 미래 세션을 이끌 명백하지 않은 교훈, 핵심 통찰, 명시된 사전 지식을 캡처. 근접 발달 영역 계산에 사용.

## 템플릿

```md
# {배웠거나 확립된 것의 짧은 제목}

{1-3문장: 무엇을 배웠는지 (또는 어떤 사전 지식이 확립되었는지), 그리고 그것이 미래 세션에 중요한 이유.}
```

이것이 전체 형식. 학습 기록은 한 문단이어도 됨. 가치는 이것이 _이제 알려졌다는 것_과 _다음에 무엇을 가르칠지 변경하는 이유_를 기록하는 데 있음 — 섹션 채우기에 있지 않음.

## 선택적 섹션

진정한 가치를 더할 때만 포함. 대부분의 기록에는 필요하지 않음.

- **Status** 프론트매터 (`active | superseded by LR-NNNN`) — 이전 이해가 틀렸다고 판명되어 교체될 때 유용.
- **Evidence** — 사용자가 이해를 어떻게 입증했는지 (답변된 질문, 완료된 연습, 인용된 사전 경험). 주장이 재검토될 수 있을 때 유용.
- **Implications** — 미래 세션에서 무엇이 풀리거나 배제되는지. 명백하지 않을 때 기록할 가치 있음.

## 번호 매기기

`./learning-records/`에서 가장 높은 기존 번호를 스캔하고 1씩 증가.

## 학습 기록을 작성하는 시기

다음 중 하나라도 참일 때 작성:

1. **사용자가 사소하지 않은 것에 대한 진정한 이해를 입증** — 단순한 노출이 아니라 개념을 올바르게 사용할 수 있다는 증거. 다음에 무엇을 가르칠지에 대한 새 기준 설정.
2. **사용자가 사전 지식을 공개** — "나는 이미 X를 알아." 미래 세션이 다시 가르치지 않도록 기록. 주장된 _깊이_도 기록.
3. **오해가 수정됨** — 사용자가 이전에 잘못된 것을 믿었고 이제 이유를 앎. 높은 가치: 관련 주제에 대한 미래 장애물을 예측.
4. **학습에 응답하여 미션이 변경됨** — 사용자가 생각했던 것과 다른 것에 관심 있다는 것을 발견. [[MISSION.md]]에 교차 링크하고 업데이트.

### 자격이 없는 것

- 단순히 다룬 자료. 다루는 것은 학습이 아님. 증거를 기다리기.
- [[GLOSSARY.md]]에 용어 정의로 이미 간결하게 캡처된 모든 것. 중복하지 말기.
- 세션별 활동 로그. 학습 기록은 일지가 아님 — 결정급 통찰.

## 대체

나중 기록이 이전 기록과 모순될 때 (사용자의 이해가 깊어지거나 수정됨), 삭제하지 말고 이전 기록에 `Status: superseded by LR-NNNN` 표시. 이해가 어떻게 진화했는지의 이력 자체가 유용한 신호.
