# MISSION.md 형식

`MISSION.md`는 워크스페이스 루트에 있음. 사용자가 이 주제를 배우는 _이유_를 캡처. 모든 교육 결정 — 다음에 무엇을 가르칠지, 어떤 자원을 표면화할지, 어떤 연습문제를 설계할지 — 은 이 문서로 거슬러 올라가야 함.

## 템플릿

```md
# 미션: {주제}

## 이유
{1-3문장. 사용자가 추구하는 구체적인 실제 세계 목표. 이 스킬이 있을 때 그들의 삶이나 업무에서 무엇이 바뀌는가? "X를 이해하기 위해" 같은 추상적 프레이밍 피하기 — 근본적인 결과물을 추구.}

## 성공의 모습
- {사용자가 할 수 있게 될 구체적이고 관찰 가능한 것}
- {또 다른 구체적인 것}
- {…}

## 제약
- {시간, 예산, 사전 약속, 학습 선호도, 접근법을 제한하는 모든 것}

## 범위 외
- {사용자가 현재 명시적으로 추구하고 싶지 않은 인접 주제 — 근접 발달 영역 보호}
```

## 규칙

- **워크스페이스당 하나의 미션.** 사용자가 관련 없는 두 가지를 배우고 싶다면 두 개의 워크스페이스.
- **추상 대신 구체.** "더 건강해지기"보다 "10월까지 하프 마라톤 완주". "Rust 배우기"보다 "팀에 Rust CLI 배포".
- **모호함에 반발.** 사용자가 이유를 설명할 수 없으면 작성 전에 인터뷰. 나쁜 미션은 미션 없음보다 나쁨.
- **현실이 바뀌면 수정.** 미션은 변함. 사용자의 목표가 이동하면 이 파일 업데이트 — 오래된 미션이 미래 세션을 이끌게 두지 말기.
- **짧게 유지.** `MISSION.md`가 한 화면을 넘으면 나침반을 멈추고 계획이 되기 시작한 것.
