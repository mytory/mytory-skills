# GLOSSARY.md 형식

`GLOSSARY.md`는 이 교육 워크스페이스의 공식 언어. 모든 설명, 연습문제, 학습 기록은 그 용어를 준수해야 함. 용어집을 만드는 것 자체가 학습의 일부: 개념을 간결한 정의로 압축하는 것은 사용자가 이해했다는 증거.

## 구조

```md
# {주제} 용어집

{이 용어집이 다루는 주제에 대한 한두 문장 설명.}

## 용어

**비대 (Hypertrophy)**:
반복된 훈련 세션에 걸친 기계적 긴장과 대사 스트레스로 인한 근육 성장.
_피할 것_: 벌크업, 커지기

**점진적 과부하 (Progressive overload)**:
부하, 볼륨, 또는 강도를 통해 시간에 따라 근육에 대한 요구를 체계적으로 증가시키는 것.
_피할 것_: 더 열심히 하기, 레벨업

**RPE (자각적 운동 강도)**:
세트가 얼마나 힘들었는지에 대한 1-10 자기 평가, 10은 실패, 8은 두 번 더 할 수 있었음을 의미.
_피할 것_: 노력 점수, 강도 등급
```

## 규칙

- **사용자가 이해했을 때만 용어 추가.** 용어집은 사용자가 읽고 배우는 사전이 아니라 압축된 지식의 기록. 사용자가 방금 개념을 소개받았다면, 올바르게 사용할 수 있을 때까지 기다렸다가 여기로 승격.
- **주관적이세요.** 여러 단어가 같은 개념에 존재하면 가장 좋은 것을 고르고 나머지는 피해야 할 별칭으로 나열. 이것이 언어가 압축되는 방식.
- **정의는 간결하게.** 한두 문장. 용어가 무엇인지 정의하고, 무엇을 하는지 또는 어떻게 하는지 정의하지 않음.
- **정의 안에서 용어집 자체 용어 사용.** 용어집에 들어간 용어는 모든 곳에서 선호 — 다른 정의 안에서도 포함. 복잡한 용어를 나중에 더 쉽게 파악하게 만드는 것.
- **자연스러운 군집이 생기면 하위 제목 아래 그룹화** (예: `## 해부학`, `## 프로그래밍`). 용어가 응집되면 평면 목록도 괜찮음.
- **모호성을 명시적으로 지적.** 용어가 더 넓은 분야에서 느슨하게 사용되면 해결책 기록: "이 워크스페이스에서 'set'은 항상 워킹 세트를 의미 — 웜업은 별도로 추적."
- **이해가 깊어지면 수정.** 사용자가 1주차에 쓴 정의가 6주차에는 틀릴 수 있음. 제자리에서 업데이트; 오래된 항목 방치 금지.
