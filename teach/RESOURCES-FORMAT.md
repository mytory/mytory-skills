# RESOURCES.md 형식

`RESOURCES.md`는 이 주제에 대한 신뢰할 수 있는 출처의 큐레이션된 집합. 설명을 위한 지식은 파라메트릭 추측이 아닌 여기에서 도출. 지혜는 여기 나열된 커뮤니티에서 비롯.

## 구조

```md
# {주제} 자료

## 지식

- [책: _근력 트레이닝의 과학과 실천_ — Zatsiorsky & Kraemer](https://example.com)
  프로그래밍과 적응에 관한 기초 텍스트. 사용 대상: 주기화, 회복, 강도 영역 관련 모든 것.
- [기사: "얼마나 훈련해야 하나?" — Greg Nuckols (Stronger By Science)](https://example.com)
  볼륨 기준점에 대한 증거 기반 리뷰. 사용 대상: 근육 그룹별 주간 세트 목표.

## 지혜 (커뮤니티)

- [r/weightroom](https://reddit.com/r/weightroom)
  브로사이언스에 대해 모더레이션된 고신호 서브레딧. 사용 대상: 프로그램 비평, 정체기 문제 해결.
- 로컬: {체육관 이름} 화요일 근력 수업
  사용 대상: 리프트에 대한 실시간 코칭 피드백.
```

## 규칙

- **고신뢰만.** 1차 출처, 인정받은 전문가, 피어 리뷰 작업, 강력한 모더레이션이 있는 커뮤니티 선호. 마케팅이 교육으로 위장된 자료는 제외.
- **모든 항목에 주석.** 3개월 후에 맨 링크는 쓸모없음. 한 줄 추가: 무엇을 다루고 언제 찾을지.
- **지식 / 지혜로 그룹화.** [SKILL.md](./SKILL.md)의 철학 반영. 자료가 한 그룹에만 나타나도 괜찮음.
- **간극을 명시적으로 표면화.** 미션이 필요한 영역에 좋은 자료가 없으면 누락된 것을 나열하는 `## 간극` 섹션 작성. 미래 검색을 구동.
- **무자비하게 정리.** 틀렸거나, 얕거나, 미션에서 벗어난 자료는 묻지 말고 제거. 서른 개의 평범한 것보다 다섯 개의 날카로운 출처가 나음.
- **커뮤니티 선호도 기록.** 사용자가 커뮤니티 참여를 거부했으면 여기 기록하여 미래 세션이 계속 제안하지 않게.
