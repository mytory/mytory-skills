# 하이 에이전시 프론트엔드 스킬

## 1. 활성 기준선 설정
* DESIGN_VARIANCE: 8 (1=완벽 대칭, 10=예술적 혼돈)
* MOTION_INTENSITY: 6 (1=정적/움직임 없음, 10=시네마틱/매직 물리)
* VISUAL_DENSITY: 4 (1=아트 갤러리/에어리, 10=파일럿 칵핏/데이터 밀집)

**AI 지침:** 모든 생성을 위한 표준 기준선은 엄격히 이 값들(8, 6, 4)로 설정됩니다. 사용자에게 이 파일을 편집하라고 요청하지 마세요. 그 외에는 항상 사용자의 말을 들으세요: 채팅 프롬프트에서 명시적으로 요청하는 내용에 따라 이 값들을 동적 조정. 이 기준선(또는 사용자 재정의) 값을 전역 변수로 사용해 섹션 3~7의 특정 로직을 구동.

## 2. 기본 아키텍처 & 관례
사용자가 다른 스택을 명시하지 않는 한, 일관성을 위해 이 구조적 제약 준수:

* **의존성 검증 [필수]:** 타사 라이브러리(예: `framer-motion`, `lucide-react`, `zustand`)를 임포트하기 전에 반드시 `package.json` 확인. 패키지가 없으면 코드 제공 전에 설치 명령어(예: `npm install package-name`) 출력 필수. 라이브러리가 존재한다고 **절대** 가정 말 것.
* **프레임워크 & 인터랙티비티:** React 또는 Next.js. 기본값 Server Components (`RSC`).
    * **RSC 안전:** 전역 상태는 Client Components에서만 작동. Next.js에서 프로바이더는 `"use client"` 컴포넌트로 감싸기.
    * **인터랙티비티 격리:** 섹션 4 또는 7(Motion/Liquid Glass)이 활성화된 경우, 특정 인터랙티브 UI 컴포넌트는 맨 위에 `'use client'`가 있는 격리된 리프 컴포넌트로 추출 필수. Server Components는 정적 레이아웃만 렌더링.
* **상태 관리:** 격리된 UI에는 로컬 `useState`/`useReducer` 사용. 깊은 prop 드릴링 회피에만 엄격히 전역 상태 사용.
* **스타일링 정책:** Tailwind CSS (v3/v4)로 90% 스타일링.
    * **TAILWIND 버전 고정:** 먼저 `package.json` 확인. v3 프로젝트에서 v4 문법 사용 금지.
    * **T4 설정 가드:** v4의 경우, `postcss.config.js`에 `tailwindcss` 플러그인 사용 금지. `@tailwindcss/postcss` 또는 Vite 플러그인 사용.
* **안티 이모지 정책 [중요]:** 코드, 마크업, 텍스트 콘텐츠, 대체 텍스트에 절대 이모지 사용 금지. 기호를 고품질 아이콘(Radix, Phosphor)이나 깔끔한 SVG 프리미티브로 교체. 이모지는 금지.
* **반응성 & 간격:**
  * 중단점 표준화 (`sm`, `md`, `lg`, `xl`).
  * `max-w-[1400px] mx-auto` 또는 `max-w-7xl`로 페이지 레이아웃 제한.
  * **뷰포트 안정성 [중요]:** 전체 높이 히어로 섹션에 절대 `h-screen` 사용 금지. 모바일 브라우저(iOS Safari)의 치명적 레이아웃 점핑 방지를 위해 항상 `min-h-[100dvh]` 사용.
  * **Flex-Math보다 Grid:** 복잡한 flexbox 백분율 계산(`w-[calc(33%-1rem)]`) 절대 사용 금지. 신뢰할 수 있는 구조에는 항상 CSS Grid(`grid grid-cols-1 md:grid-cols-3 gap-6`) 사용.
* **아이콘:** 임포트 경로로 정확히 `@phosphor-icons/react` 또는 `@radix-ui/react-icons` 사용 (설치된 버전 확인). `strokeWidth` 전역 표준화 (예: `1.5` 또는 `2.0` 독점 사용).

## 3. 디자인 엔지니어링 지침 (편향 보정)
LLM은 특정 UI 클리셰 패턴에 통계적 편향이 있음. 이 설계된 규칙으로 프리미엄 인터페이스 선제적 구축:

**규칙 1: 결정론적 타이포그래피**
* **디스플레이/헤드라인:** 기본값 `text-4xl md:text-6xl tracking-tighter leading-none`.
    * **안티 슬롭:** "프리미엄" 또는 "크리에이티브" 분위기에 `Inter` 사용 자제. `Geist`, `Outfit`, `Cabinet Grotesk`, `Satoshi`로 독특한 개성 강제.
    * **테크니컬 UI 규칙:** 대시보드/소프트웨어 UI에 세리프 폰트 엄격히 금지. 이 컨텍스트에는 고급 산세리프 페어링만 사용(`Geist` + `Geist Mono` 또는 `Satoshi` + `JetBrains Mono`).
* **본문/문단:** 기본값 `text-base text-gray-600 leading-relaxed max-w-[65ch]`.

**규칙 2: 색상 보정**
* **제약:** 최대 1개 강조색. 채도 < 80%.
* **LILA 금지:** "AI 보라/파랑" 미학 엄격히 금지. 보라 버튼 글로우, 네온 그라데이션 금지. 절대 중립 베이스(Zinc/Slate)에 고대비 단일 강조색(예: Emerald, Electric Blue, Deep Rose) 사용.
* **색상 일관성:** 전체 출력에 하나의 팔레트 고수. 같은 프로젝트 내에서 따뜻한 회색과 차가운 회색 변동 금지.

**규칙 3: 레이아웃 다양화**
* **안티 센터 편향:** `LAYOUT_VARIANCE > 4`일 때 중앙 정렬 히어로/H1 섹션 엄격히 금지. "분할 화면"(50/50), "좌측 정렬 콘텐츠/우측 정렬 자산", "비대칭 화이트스페이스" 구조 강제.

**규칙 4: 재질감, 그림자, "안티 카드 과사용"**
* **대시보드 강화:** `VISUAL_DENSITY > 7`일 때 일반 카드 컨테이너 엄격히 금지. `border-t`, `divide-y`, 순수 여백으로 로직 그룹핑 사용. 상승(z-index)이 기능적으로 필요하지 않은 한 데이터 메트릭은 박스 없이 숨 쉬어야 함.
* **실행:** 상승이 계층을 전달할 때만 카드 사용. 그림자 사용 시 배경 색조로 틴트.

**규칙 5: 인터랙티브 UI 상태**
* **필수 생성:** LLM은 자연스럽게 "정적" 성공 상태 생성. 전체 인터랙션 사이클 구현 필수:
  * **로딩:** 레이아웃 크기와 일치하는 스켈레톤 로더 (일반 원형 스피너 회피).
  * **빈 상태:** 데이터 채우기 방법을 나타내는 아름답게 구성된 빈 상태.
  * **오류 상태:** 명확한 인라인 오류 보고 (예: 폼).
  * **촉각 피드백:** `:active`에서 `-translate-y-[1px]` 또는 `scale-[0.98]`로 물리적 누름 시뮬레이션하여 성공/액션 표시.

**규칙 6: 데이터 & 폼 패턴**
* **폼:** 라벨은 입력 위에 위치 필수. 도움말 텍스트는 선택이지만 마크업에 존재해야 함. 오류 텍스트는 입력 아래. 입력 블록에 표준 `gap-2` 사용.

## 4. 창의적 선제성 (안티 슬롭 구현)
제네릭 AI 디자인에 적극 대응하기 위해 이 하이엔드 코딩 개념을 기준선으로 체계적 구현:
* **"리퀴드 글래스" 굴절:** 글래스모피즘이 필요하면 `backdrop-blur`를 넘어서기. 1px 내부 보더(`border-white/10`)와 미묘한 내부 그림자(`shadow-[inset_0_1px_0_rgba(255,255,255,0.1)]`)로 물리적 가장자리 굴절 시뮬레이션.
* **마그네틱 마이크로 물리 (MOTION_INTENSITY > 5인 경우):** 마우스 커서 쪽으로 살짝 당겨지는 버튼 구현. **중요:** 마그네틱 호버나 연속 애니메이션에 절대 React `useState` 사용 금지. 모바일 성능 붕괴 방지를 위해 React 렌더 사이클 외부에서 독점적으로 Framer Motion의 `useMotionValue`와 `useTransform` 사용.
* **지속적 마이크로 인터랙션:** `MOTION_INTENSITY > 5`일 때, 표준 컴포넌트(아바타, 상태 점, 배경)에 연속적 무한 마이크로 애니메이션(Pulse, Typewriter, Float, Shimmer, Carousel) 임베드. 모든 인터랙티브 요소에 프리미엄 Spring Physics(`type: "spring", stiffness: 100, damping: 20`) 적용 — 선형 이징 금지.
* **레이아웃 트랜지션:** 상태 변경 간 부드러운 재정렬, 크기 조정, 공유 요소 전환을 위해 항상 Framer Motion의 `layout`과 `layoutId` props 활용.
* **엇갈린 오케스트레이션:** 리스트나 그리드를 즉시 마운트 금지. `staggerChildren`(Framer) 또는 CSS 캐스케이드(`animation-delay: calc(var(--index) * 100ms)`)로 순차적 워터폴 노출 생성. **중요:** `staggerChildren`의 경우, 부모(`variants`)와 자식은 반드시 동일한 Client Component 트리에 존재. 데이터가 비동기로 페치되면 중앙 집중형 부모 Motion 래퍼에 props로 데이터 전달.

## 5. 성능 가드레일
* **DOM 비용:** 그레인/노이즈 필터는 고정, pointer-event-none 의사 요소(예: `fixed inset-0 z-50 pointer-events-none`)에만 독점 적용, 스크롤 컨테이너에는 절대 적용 금지 — 지속적 GPU 리페인트와 모바일 성능 저하 방지.
* **하드웨어 가속:** `top`, `left`, `width`, `height` 애니메이션 금지. `transform`과 `opacity`로만 애니메이션.
* **Z-Index 절제:** 요청 없이 임의의 `z-50`이나 `z-10` 스팸 금지. 시스템 레이어 컨텍스트(고정 내비바, 모달, 오버레이)에만 엄격히 z-index 사용.

## 6. 기술 참조 (다이얼 정의)

### DESIGN_VARIANCE (레벨 1-10)
* **1-3 (예측 가능):** Flexbox `justify-center`, 엄격한 12열 대칭 그리드, 균등 패딩.
* **4-7 (오프셋):** `margin-top: -2rem` 겹침, 다양한 이미지 종횡비(예: 4:3 옆에 16:9), 중앙 정렬 데이터 위 왼쪽 정렬 헤더.
* **8-10 (비대칭):** 메이슨리 레이아웃, 분수 단위 CSS Grid(예: `grid-template-columns: 2fr 1fr 1fr`), 거대한 빈 영역(`padding-left: 20vw`).
* **모바일 오버라이드:** 레벨 4-10의 경우, `md:` 이상의 비대칭 레이아웃은 뷰포트 `< 768px`에서 엄격한 단일 열 레이아웃(`w-full`, `px-4`, `py-8`)으로 공격적 폴백하여 수평 스크롤과 레이아웃 파손 방지.

### MOTION_INTENSITY (레벨 1-10)
* **1-3 (정적):** 자동 애니메이션 없음. CSS `:hover`와 `:active` 상태만.
* **4-7 (유체 CSS):** `transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1)` 사용. 로드인에 `animation-delay` 캐스케이드 사용. `transform`과 `opacity`에만 엄격히 집중. `will-change: transform` 드물게 사용.
* **8-10 (고급 안무):** 복잡한 스크롤 트리거 노출 또는 패럴랙스. Framer Motion 훅 사용. 절대 `window.addEventListener('scroll')` 사용 금지.

### VISUAL_DENSITY (레벨 1-10)
* **1-3 (아트 갤러리 모드):** 많은 화이트스페이스. 거대한 섹션 간격. 모든 것이 매우 고가이고 깔끔하게 느껴짐.
* **4-7 (일상 앱 모드):** 표준 웹 앱용 일반 간격.
* **8-10 (칵핏 모드):** 작은 패딩. 카드 박스 없음; 데이터 분리는 1px 선만. 모든 것이 밀집. **필수:** 모든 숫자에 고정폭(`font-mono`) 사용.

## 7. AI 표시 (금지 패턴)
프리미엄, 비제네릭 출력 보장을 위해 명시적 요청이 없는 한 이 일반적인 AI 디자인 시그니처 엄격 회피:

### 비주얼 & CSS
* **네온/외부 글로우 금지:** 기본 `box-shadow` 글로우나 자동 글로우 사용 금지. 내부 보더나 미묘한 틴트 그림자 사용.
* **순수 검정 금지:** 절대 `#000000` 사용 금지. 오프블랙, Zinc-950, 차콜 사용.
* **과채도 강조색 금지:** 중립색과 우아하게 혼합되도록 강조색 탈채도.
* **과도한 그라데이션 텍스트 금지:** 큰 헤더에 text-fill 그라데이션 사용 금지.
* **커스텀 마우스 커서 금지:** 구식이며 성능/접근성 파괴.

### 타이포그래피
* **Inter 폰트 금지:** 금지. `Geist`, `Outfit`, `Cabinet Grotesk`, `Satoshi` 사용.
* **과대한 H1 금지:** 첫 헤딩이 소리쳐서는 안 됨. 거대한 스케일이 아닌 굵기와 색상으로 계층 제어.
* **세리프 제약:** 창의적/에디토리얼 디자인에만 세리프 폰트 사용. 깔끔한 대시보드에는 **절대** 세리프 사용 금지.

### 레이아웃 & 간격
* **완벽 정렬 & 간격:** 패딩과 마진이 수학적으로 완벽함 보장. 어색한 간격이 있는 플로팅 요소 회피.
* **3열 카드 레이아웃 금지:** 제네릭 "3개 동등 카드 수평" 기능 행 금지. 2열 지그재그, 비대칭 그리드, 수평 스크롤 접근법 사용.

### 콘텐츠 & 데이터 ("Jane Doe" 효과)
* **제네릭 이름 금지:** "John Doe", "Sarah Chan", "Jack Su" 금지. 매우 창의적이고 현실감 있는 이름 사용.
* **제네릭 아바타 금지:** 아바타에 표준 SVG "에그"나 Lucide 사용자 아이콘 사용 금지. 창의적이고 믿을 수 있는 사진 플레이스홀더나 특정 스타일링 사용.
* **가짜 숫자 금지:** `99.99%`, `50%`, 기본 전화번호(`1234567`) 같은 예측 가능한 출력 회피. 유기적이고 지저분한 데이터 사용(`47.2%`, `+1 (312) 847-1928`).
* **스타트업 슬롭 이름 금지:** "Acme", "Nexus", "SmartFlow". 프리미엄, 맥락적 브랜드명 발명.
* **필러 단어 금지:** "Elevate", "Seamless", "Unleash", "Next-Gen" 같은 AI 카피라이팅 클리셰 회피. 구체적 동사 사용.

### 외부 자원 & 컴포넌트
* **깨진 Unsplash 링크 금지:** Unsplash 사용 금지. `https://picsum.photos/seed/{random_string}/800/600` 또는 SVG UI 아바타 같은 절대적이고 신뢰할 수 있는 플레이스홀더 사용.
* **shadcn/ui 커스터마이제이션:** `shadcn/ui` 사용 가능하지만 절대 제네릭 기본 상태로 사용 금지. 하이엔드 프로젝트 미학에 맞게 반경, 색상, 그림자 커스터마이즈 필수.
* **프로덕션 레디 청결도:** 코드는 매우 깨끗하고, 시각적으로 강렬하며, 기억에 남고, 모든 세부사항에서 세심하게 정제되어야 함.

## 8. 창의적 무기고 (하이엔드 영감)
제네릭 UI에 기본값 사용 금지. 출력이 시각적으로 강렬하고 기억에 남도록 이 고급 개념 라이브러리에서 가져오기. 적절할 때 기본 CSS 모션 대신 복잡한 스크롤텔링에 **GSAP (ScrollTrigger/Parallax)**, 3D/Canvas 애니메이션에 **ThreeJS/WebGL** 활용. **중요:** 동일 컴포넌트 트리에서 GSAP/ThreeJS와 Framer Motion 혼합 금지. UI/벤토 인터랙션에는 기본값 Framer Motion. GSAP/ThreeJS는 엄격한 useEffect 정리 블록으로 감싼 격리된 전체 페이지 스크롤텔링이나 캔버스 배경에만 독점 사용.

### 표준 히어로 패러다임
* 어두운 이미지 위 중앙 텍스트 그만. 비대칭 히어로 섹션 시도: 텍스트 깔끔하게 왼쪽 또는 오른쪽 정렬. 배경은 고품질 관련 이미지와 미묘한 스타일리시 페이드(라이트 또는 다크 모드에 따라 우아하게 어두워지거나 밝아져 배경색으로 자연스럽게 전환).

### 내비게이션 & 메뉴
* **Mac OS Dock 확대:** 가장자리에 내비 바; 호버 시 아이콘이 유체처럼 스케일.
* **마그네틱 버튼:** 커서 쪽으로 물리적으로 당겨지는 버튼.

## 9. "모션 엔진" 벤토 패러다임
현대적 SaaS 대시보드나 기능 섹션 생성 시, 다음 "벤토 2.0" 아키텍처와 모션 철학 활용 필수. 정적 카드를 넘어서 지속적 물리에 의존하는 "Vercel-core meets Dribbble-clean" 미학 강제.

### A. 핵심 디자인 철학
* **미학:** 하이엔드, 미니멀, 기능적.
* **팔레트:** 배경 `#f9fafb`. 카드는 순수 화이트(`#ffffff`)에 `border-slate-200/50`의 1px 보더.
* **표면:** 모든 주요 컨테이너에 `rounded-[2.5rem]` 사용. "확산 그림자"(매우 가볍고 넓게 퍼지는 그림자, 예: `shadow-[0_20px_40px_-15px_rgba(0,0,0,0.05)]`)로 혼란 없이 깊이 생성.
* **타이포그래피:** 엄격한 `Geist`, `Satoshi`, `Cabinet Grotesk` 폰트 스택. 헤더에 미묘한 트래킹(`tracking-tight`) 사용.
* **라벨:** 제목과 설명은 갤러리 스타일 프레젠테이션 유지를 위해 카드 **바깥과 아래**에 배치.
* **픽셀 완벽:** 카드 내부에 넉넉한 `p-8` 또는 `p-10` 패딩 사용.

### B. 애니메이션 엔진 명세 (지속적 모션)
모든 카드는 **"지속적 마이크로 인터랙션"** 포함 필수. 다음 Framer Motion 원칙 사용:
* **스프링 물리:** 선형 이징 금지. 프리미엄 무게감을 위해 `type: "spring", stiffness: 100, damping: 20` 사용.
* **레이아웃 트랜지션:** 부드러운 재정렬, 크기 조정, 공유 요소 상태 전환을 위해 `layout`과 `layoutId` props 대폭 활용.
* **무한 루프:** 대시보드가 "살아있는" 느낌을 보장하기 위해 모든 카드는 무한 반복되는 "활성 상태"(Pulse, Typewriter, Float, Carousel)를 가져야 함.
* **성능:** 동적 리스트를 `<AnimatePresence>`로 감싸고 60fps 최적화. **성능 중요:** 모든 지속적 모션이나 무한 루프는 반드시 메모화(React.memo)되고 자체 미세 Client Component에 완전히 격리. 부모 레이아웃에서 재렌더링 트리거 금지.

### C. 5카드 원형 (마이크로 애니메이션 명세)
벤토 그리드 구축 시(예: 행 1: 3열 | 행 2: 2열 70/30 분할) 이 특정 마이크로 애니메이션 구현:
1. **인텔리전트 리스트:** 무한 자동 정렬 루프가 있는 항목 수직 스택. `layoutId`로 항목 위치 교체, AI가 실시간 작업 우선순위 지정 시뮬레이션.
2. **명령 입력:** 다단계 Typewriter Effect가 있는 검색/AI 바. 복잡한 프롬프트 순환, 깜박이는 커서, 쉬머링 로딩 그라데이션의 "처리 중" 상태 포함.
3. **라이브 상태:** "숨쉬는" 상태 표시기가 있는 스케줄링 인터페이스. "Overshoot" 스프링 효과로 나타나고 3초 유지 후 사라지는 팝업 알림 배지 포함.
4. **와이드 데이터 스트림:** 데이터 카드나 메트릭의 수평 "Infinite Carousel". 쉽게 느껴지는 속도로 매끄러운 루프(`x: ["0%", "-100%"]`) 보장.
5. **컨텍스트 UI (포커스 모드):** 텍스트 블록의 엇갈린 하이라이트 애니메이션 후 마이크로 아이콘이 있는 플로팅 액션 툴바의 "Float-in"이 있는 문서 뷰.
