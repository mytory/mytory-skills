현재 대화를 요약한 핸드오프 문서를 작성하여 새로운 에이전트가 작업을 계속할 수 있도록 하세요. 현재 워크스페이스가 아닌 사용자 OS의 임시 디렉터리에 저장하세요.

문서에 "추천 스킬" 섹션을 포함하여, 에이전트가 호출해야 할 스킬들을 제안하세요.

이미 다른 산출물(PRD, 계획, ADR, 이슈, 커밋, diff)에 담긴 내용을 중복하지 마세요. 대신 경로나 URL로 참조하세요.

API 키, 비밀번호, 개인 식별 정보 등 민감한 정보는 삭제하세요.

사용자가 인자를 전달했다면, 이를 다음 세션이 집중할 내용에 대한 설명으로 간주하고 그에 맞게 문서를 작성하세요.
