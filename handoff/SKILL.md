새 에이전트가 작업을 이어갈 수 있도록 현재 대화를 요약한 인수인계 문서를 작성하세요. 현재 작업 공간이 아닌 사용자 운영체제의 임시 디렉터리(`$TMPDIR`, 없으면 `/tmp`; Windows에서는 `%TEMP%`)에 저장하세요.

문서에 "추천 스킬" 섹션을 넣고, 다음 에이전트가 Skill 도구로 호출해야 할 스킬 이름을 적으세요.

명세, 계획, ADR, 이슈, 커밋, diff 등 다른 산출물에 이미 담긴 내용을 중복해서 적지 마세요. 대신 해당 경로나 URL을 참조하세요.

API 키, 비밀번호, 개인 식별 정보 등 민감한 정보는 제거하세요.

사용자가 인자를 전달했다면 이를 다음 세션의 작업 초점으로 해석하고 그에 맞게 문서를 작성하세요.
