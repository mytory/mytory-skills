# 분류 라벨

스킬은 다섯 가지 공식 분류 역할로 대화합니다. 이 파일은 그 역할을 이 저장소의 이슈 트래커에서 사용되는 실제 라벨 문자열로 매핑합니다.

| mattpocock/skills의 라벨  | 우리 트래커의 라벨    | 의미                                        |
| ------------------------- | --------------------- | ------------------------------------------- |
| `needs-triage`            | `needs-triage`        | 메인테이너가 이 이슈 평가 필요              |
| `needs-info`              | `needs-info`          | 보고자의 추가 정보 대기 중                  |
| `ready-for-agent`         | `ready-for-agent`     | 완전히 명세화됨, AFK 에이전트 대응 가능     |
| `ready-for-human`         | `ready-for-human`     | 사람 구현 필요                              |
| `wontfix`                 | `wontfix`             | 조치되지 않을 것                            |

스킬이 역할을 언급할 때(예: "AFK-ready 분류 라벨 적용"), 이 테이블의 해당 라벨 문자열 사용.

실제로 사용하는 어휘에 맞게 오른쪽 열을 편집하세요.
