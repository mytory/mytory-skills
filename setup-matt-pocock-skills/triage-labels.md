# 분류 라벨

스킬은 다섯 가지 표준 분류 역할을 사용합니다. 이 파일은 각 역할을 저장소의 이슈 트래커에서 사용하는 실제 라벨 문자열에 대응시킵니다.

| mattpocock/skills의 라벨 | 이 저장소 트래커의 라벨 | 의미                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 관리자의 이슈 평가 필요  |
| `needs-info`               | `needs-info`         | 제보자의 추가 정보 대기 |
| `ready-for-agent`          | `ready-for-agent`    | 명세가 완성되어 AFK 에이전트 작업 가능 |
| `ready-for-human`          | `ready-for-human`    | 사람의 구현 필요 |
| `wontfix`                  | `wontfix`            | 처리하지 않음 |

스킬이 역할을 언급하면 (예: "AFK 작업 가능 분류 라벨 적용") 이 표의 해당 라벨 문자열을 사용하세요.

실제로 사용하는 용어에 맞게 "이 저장소 트래커의 라벨" 열을 편집하세요.
