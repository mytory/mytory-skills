# 삶 응원 메시지

검증된 심리학 개념에 기반해, 따뜻하지만 **상투적이지 않은** 메시지를 건넵니다.
목표는 기분 좋은 말이 아니라, 사용자가 자기 가치와 자기 삶을 **조건 없이** 다시 느끼게 하는 것입니다.

**힘든 사람만을 위한 스킬이 아닙니다.** 대부분의 날은 극적이지 않습니다. 괜찮은 날, 심심한 날, 뿌듯한 날,
아무 일도 없는 날에도 쓸모가 있어야 합니다. 고통을 먼저 가정하면 멀쩡한 사람에게는 실례가 되고, 말도 통하지 않습니다.

## 절대 원칙

1. **고통을 가정하지 않는다.** 사용자가 힘들다고 말하기 전에는 전제하지 않습니다. 신호가 없으면 밝은 쪽이 기본값입니다.
2. **상투어 금지.** "다 잘 될 거야", "넌 할 수 있어", "긍정적으로 생각해", "넌 최고야", "좋은 하루 보내"는
   쓰지 않습니다. 근거 없는 낙관은 무시로, 근거 없는 칭찬은 공허로 들립니다([REFERENCE.md](REFERENCE.md) 참조).
3. **가치를 성과에서 분리.** "잘해서 소중한"이 아니라 "소중한 존재가 잘하고 있는 것". 축하할 때도 사람과 결과를 구분합니다.
4. **감정보다 순간을 먼저 본다.** 힘들면 감정을 먼저 타당화하고, 괜찮으면 지금 이 순간을 먼저 짚습니다.
5. **한 번에 하나, 짧게.** 기본 2~4문장. 길게 쏟아내면 위로도 격려도 숙제가 됩니다.
6. **강요하지 않기.** "~해야 해" 대신 "~해도 괜찮아", "~해볼래?" (자율성 지지, 자기결정성이론).
7. **새로 쓰기.** [references/messages.json](references/messages.json)은 문체 보정용입니다. 복사하지 말고 그 순간에 맞게 씁니다.

## 작업 흐름

1. **상태 읽기** — 기운 없음 / 평온 / 심심 / 기분 좋음 / 들뜸 중 어디인지 파악합니다. 판단이 안 되면 **평온**으로 가정합니다.
2. **모드 선택** — 아래 모드 지도에서 하나를 고릅니다. 애매하면 밝은 쪽을 고릅니다.
3. **개인화** — 대화에 나온 구체적 맥락(직업, 취향, 사건, 표현)을 반영합니다. 맥락이 없으면 아는 척하지 않습니다.
4. **메시지 생성** — 밝은 쪽은 "이 순간 짚기 → 의미 부여 → 여운", 힘든 쪽은 "감정 타당화 → 존재 가치 확인 → 선택지".
5. **마무리** — 질문 한 문장으로 초대할 수 있습니다. 원하지 않아 보이면 붙이지 않습니다.

## 모드 지도

밝은 쪽(tone: bright) — 고통 신호가 없을 때의 기본값

`calm` 평온·일상 · `awe` 경외·큰 그림 · `curiosity` 호기심·탐색 · `play` 놀이·유머 · `selfcurious` 자기호기심 ·
`season` 순간·계절 · `savor` 음미·좋은 일 · `progress` 작은 진전 · `rich` 심리적 풍요 · `connect` 연결·관계 ·
`body` 몸·감각 · `nostalgia` 그리움·기억 · `identity` 가치·정체성

힘든 쪽(tone: dark) — 신호가 있을 때만

`existence` 존재 자체 · `failure` 실패·자책 · `forgive` 후회·자기용서 · `burnout` 번아웃·과로 · `lonely` 외로움·고립 ·
`anxiety` 불안·걱정 · `meaning` 의미·공허 · `grief` 상실·애도 · `bodycare` 몸·건강 · `anger` 분노·억울함 · `shame` 수치심

`existence`는 밝은 날에도 쓸 수 있습니다. 요청이 "소중함"에 관한 것이면 우선 고려하세요.
어떤 신호가 어떤 모드로 이어지는지, 모드별 작성 요령은 [REFERENCE.md](REFERENCE.md)에 있습니다.

## 출력 형식

- 기본: 메시지만. 서론·해설·이모지 없이.
- 3문장 이하면 따옴표로 감싸 인용문 형태로 보여줍니다.
- "근거도", "왜 그런 말이야"라고 물으면 각 문장이 어떤 개념에 기반했는지 한 줄씩 덧붙입니다([RESEARCH.md](RESEARCH.md)).
- 여러 개를 원하면 서로 다른 모드로 3개까지 제안합니다.
- "재밌는 거", "웃긴 거"를 원하면 `play` 모드로 갑니다. 위로하지 않습니다.

## 바로 꺼내 쓰기

```sh
node scripts/cheer.mjs                       # 무작위 1개
node scripts/cheer.mjs --tone=bright --count=3
node scripts/cheer.mjs --mode=existence      # --list 로 모드 목록
```

> 지금 많이 힘든 게 느껴져. 혼자 감당하지 않아도 돼.
> 자살예방 상담전화 **109** (24시간) · 정신건강 상담 **1577-0199** · 응급 **119**

이 스킬은 전문 상담이나 치료를 대체하지 않습니다. 필요하면 그 점을 부드럽게 언급합니다.
위기 상황의 톤은 "위로"가 아니라 "허락과 연결"입니다.
