# 색상

방향 시트는 역할별 이름이 붙은 팔레트를 제공합니다. 이 문서는 페이지에 단순히 색을 입히는 대신 명확한 색상 결정을 적용하는 방법입니다.

## 목차

1. 연구에서 측정한 것
2. 역할
3. 비율
4. 선과 그림자 없는 표면
5. 색상 면
6. 어두운 페이지

8. 대비
9. 금지 색상 계열과 여기서 말하는 따뜻함

## 1. 연구에서 측정한 것

- 조사 페이지의 41%는 어둡고 59%는 밝습니다. 4분의 1은 순백색, 12%는 순검정 배경입니다.
- 패널이 분류한 배색: 단색조와 강조색 하나 23%, 밝은 중성색 22%, 어두운 중성색 14%, 여러 단색 면 13%, 엄격한 두 가지 색 12%, 사진이 색상을 담당 9%, 채도 높은 단일 면 6%입니다.
- 사이트의 52%는 중성색(검정·흰색·회색) 버튼을 씁니다. 유색 버튼은 선택 사항입니다.
- 그라데이션 채움은 상위 사이트의 22%, 하위 사이트의 52%에, 그라데이션 글자는 각각 2%, 13%에 나타납니다.
- 246개 중 테라코타 주요 버튼은 하나이고 보라색 버튼은 없습니다. 이들은 갤러리보다 생성형 페이지의 색상입니다. 따뜻한 미백색 배경은 32개에 나타나며, 거의 항상 주황 강조색 대신 어두운색이나 녹색 글자색을 씁니다.
- 상위 사이트는 섹션 사이에서 페이지 바탕색을 더 자주 바꿉니다(서로 다른 섹션 바탕색 중앙값 2개 대 1개).

## 2. 역할

```css
:root {
  --bg: …;          /* 바탕: 표면의 대부분 */
  --surface: …;     /* 바탕에서 명도 한 단계 차이: 패널, 입력란, 타일 */
  --ink: …;         /* 본문과 가장 강한 표시 */
  --muted: …;       /* 보조 글자: --bg 위에서도 대비 충족 */
  --accent: …;      /* 유일한 강조색 */
  --accent-ink: …;  /* 강조색 위의 글자 */
  /* 섹션별 색상 면이 있다면 --field-1 … --field-n과 각각의 글자색 */
}
```

모든 색상에 토큰을 사용하세요. 컴포넌트에 직접 쓴 hex 값은 두 번째 팔레트의 시작입니다. 역할 사이에 회색을 추가하지 마세요. 약한 글자색은 `--muted`, 약한 표면은 `--surface`입니다.

## 3. 비율

색칠하기 전에 비율을 정하고 스크린샷으로 확인하세요.

- **바탕:** 페이지의 70–90%.
- **글자색:** 글자와 필요하다면 반전 섹션 하나(글자색이 바탕, 바탕색이 글자).
- **강조색:** 어느 화면에서도 5% 미만. 동작과 추가 반복 요소 최대 하나에만 씁니다. 다섯 군데에 나타나면 더 이상 ‘여기’를 가리키지 못합니다.

색상 면 중심 팔레트(flat-loud, pastel)는 다릅니다. 각 섹션에 온전한 색상 면 하나를 쓰고 섹션 내부에서 면과 그 글자색만으로 비율을 지킵니다.

방향 시트가 지정하지 않는 한 강조색은 제목·아이콘·불릿·테두리·밑줄에 쓰지 않습니다. 헤드라인은 글자색입니다.

## 4. 선과 그림자 없는 표면

선과 그림자가 금지되므로 명도만으로 표면과 바탕을 구분합니다.

```css
.panel { background: var(--surface); }          /* --bg와 명도 2–6 차이 */
.field { background: var(--surface); border: 0; } /* 채운 입력란과 명확한 포커스 상태 */
.field:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }
```

- 한 단계면 충분합니다. 패널이 구분되지 않으면 다른 색조를 추가하기 전에 패딩이나 간격을 늘리세요.
- 패널 안에 패널을 넣지 마세요.
- 이미지에는 프레임이 필요 없습니다. 밝은 사진이 밝은 바탕에 묻히면 크롭을 바꾸거나 `--surface`에 놓으세요. 외곽선을 두르지 마세요.
- 글자색이나 강조색의 굵은 막대(4px 이상)는 방향에 맞으면 그래픽 요소로 허용합니다. 1px 선은 아닙니다.

## 5. 색상 면

섹션 전체의 바탕색 변경은 가장 강력한 색상 수단이며 구분선·카드·배경 장식을 동시에 대체합니다.

- 면은 경계에서 선명하게 맞닿습니다. 페이드하지 않습니다.
- 각 면에는 팔레트에서 지정한 고유 글자색이 있습니다. 유색 면에 `--muted`를 놓지 마세요. 해당 글자색을 그대로 쓰거나 대비를 만족할 때만 보조 글자의 불투명도를 70%로 낮추세요.
- 이웃한 면은 색상뿐 아니라 명도도 달라야 화면이 떨려 보이지 않습니다.
- 장처럼 배열하세요. 강하게 시작하고, 쉬고, 놀라게 하고, 어둡거나 매우 밝게 끝내세요.
- 페이지 메타 테마 색상과 내비게이션은 첫 면을 따릅니다.

## 6. 어두운 페이지

- 루트에 `color-scheme: dark`를 지정해 폼 컨트롤과 스크롤바도 따르게 하세요.
- 엄격한 두 색 방향에서 팔레트가 정확히 지정하지 않는 한, `#000` 위 `#fff` 대신 팔레트 기운이 살짝 섞인 깊은 바탕과 부드러운 밝은 글자색을 씁니다.
- 어두운 페이지는 보조 글자에서 자주 실패합니다. `--muted`와 바탕의 대비 4.5:1을 확인하세요.
- 깊이는 더 밝은 표면 단계로 만듭니다. 광채나 유색 조명을 쓰지 않습니다.
- 밝은 페이지보다 가벼운 글꼴 굵기를 쓰세요.

## 7. 색상과 사진

- 사진이 색상을 담당하면 인터페이스는 중성색을 유지하고 사진에서 가장 어두운 톤을 글자색으로 삼습니다.
- 사진에 브랜드 색을 덧씌우지 마세요. 그대로 두거나 모든 사진을 실제로 동일하게 처리하세요(모두 회색조 또는 모두 원본).
- 사진 위 글자에는 차분한 영역이 필요합니다. 없다면 글자를 사진 밖으로 옮기세요. 중성색 스크림(검정 또는 글자색, 불투명도 30–55%, 글자 영역에서만 단색 또는 점차 사라짐)은 검사기가 허용하는 유일한 그라데이션입니다.
- 사진의 하늘이나 그림자에서 뽑은 단색 면은 섹션과 이미지를 어울리게 합니다.

## 8. 대비

- 본문은 4.5:1 이상, 큰 제목과 큰 숫자는 3:1 이상입니다. 제공 팔레트의 바탕 위 글자색은 7:1을 충족합니다.
- `inspect.mjs`는 단색 배경의 글자 대비를 계산하고 2.6:1 미만이면 실패합니다. 사진 위 글자는 측정하지 못하므로 스크린샷으로 직접 확인하세요.
- 최종 대비를 확인하지 않고 글자를 ‘부드럽게’ 만들려고 불투명도를 낮추지 마세요.
- 포커스와 호버 상태는 대비를 높이며 낮추지 않습니다.

## 9. 금지 색상 계열과 여기서 말하는 따뜻함

검사기는 다음을 실패로 처리합니다.

- **크림색과 테라코타.** 노란 크림 바탕(대략 색상 22–62, 밝고 채도가 눈에 띔)에 녹·점토·탄 주황 강조색을 더한 것은 AI 비서와 생성 페이지의 전형적인 모습입니다. 각각도 의심스럽고 함께 쓰면 명백합니다.
- **바이올렛과 인디고.** 생성 페이지의 첫 유행은 보라색이었고 지금도 그렇게 읽힙니다.

브리프가 따뜻함을 원하면 저채도 돌·뼈·퍼티색 바탕(채도 약 15% 미만), 짙은 녹색·갈색·옥스블러드 글자색, 사진, 또는 머스터드·토마토 빨강·분홍의 온전한 단색 면에서 얻으세요. 따뜻함은 베이지색과 같지 않습니다.

브랜드 고유색이 금지 색상이라면 유지하세요. `--keep palette`를 쓰고 검사기에 `--allow palette-purple`(또는 해당 규칙)을 전달한 뒤 보고서에 기록하세요.
