# Backgrounds

더 나은 배경은 더 적고 더 좋은 색에서 나옵니다(집 규칙 6: "nicer backgrounds"). 테크 페이지에서는 CSS로 그린 작은 배경 목록에서도 나옵니다. 모든 종류가 세 가지 배경 토큰을 쓰며, CSS 배경은 테크만 추가합니다.

## 세 가지 토큰(모든 종류)

섹션과 패널의 배경은 `--g-main`, `--g-alt`, `--g-dark`만 씁니다(system.css: 기본, `.ground-surface`, `.ground-inverse`). 푸터를 포함해 페이지 아래로 내려가며 한 가지에서 세 가지 색을 쓰고, 390px에서도 같은 순서를 유지합니다. 사진 레이어와 아래의 테크 배경은 이 셋에 포함하지 않습니다.

- **`--g-main`:** 흰색, 또는 명도 0.80~0.97에 채도가 낮은(채널 편차 0.12 이하) 틴트이며 클라이언트에서 가져옵니다. 장소라면 벽, 종이, 가게 앞면, 상품이라면 사진 배경, 서비스라면 따뜻한 회색, 소프트웨어라면 푸른 기운이나 차가운 회색입니다. 장소는 `start.mjs deal --page place --trade <trade>`가 그 업종에 맞춰 뽑은 팔레트를 쓰며, 모든 장소에 고정된 오프화이트 하나를 쓰지 않습니다. 대부분 온라인으로 파는 가게는 흰색입니다. 페이지 높이의 55% 이상을 덮습니다(소프트웨어와 제품은 60%). 크림색 페이지에 순백 패널을 쓰지 않습니다.
- **`--g-alt`:** 같은 색조(20도 이내)에서 0.06~0.15 더 어둡게, 0.70 아래로는 내리지 않습니다(`#ffffff`에서 `#f2f2ef`, `#f7f3ec`에서 `#ede6da`). 패널, 타일, 카드, 그리고 최대 한 개의 전폭 띠에 씁니다.
- **`--g-dark`:** 명도 0.05 이하입니다. 거의 검정(`#111`에서 `#1a1a1a`)이거나 브랜드 색조의 가장 깊은 음영이며, 숯색이나 보라색은 안 됩니다. 어두운 본문 섹션은 최대 하나(한 화면 높이)이며 페이지 중간 이후에 두고, 히어로 바로 아래에는 두지 않습니다. 푸터는 어두워도 됩니다. 어두운 페이지(메인 배경 0.02 이하)와 어두운 히어로는 테크 전용입니다.
- **브랜드 띠**(`.ground-brand`, 제품과 장소): 브랜드 자체의 색(제품이나 가게 앞면에서 가져옴)으로 된 섹션 하나가 어두운 띠를 대신할 수 있으며, 후반부에 한 번만 씁니다. 장소에서는 명도 0.03~0.60, 채도 0.25 이상이어야 하고 중성적인 거의 검정은 안 됩니다. 그 위의 모든 글자(제목, 본문, 라벨, 링크)는 7:1을 통과하는 색을 쓰며 이 숫자 하나로 통일합니다. 통과할 때까지 브랜드 색을 어둡게 합니다(`check.mjs`와 `consistency.mjs`는 사람이 읽는 글자에 7:1, 라벨에 4.5:1을 요구하므로 7:1이면 둘 다 통과합니다). 기본 버튼은 반전합니다. 그 밖에 채도 높은 색은 강조색과 사진에만 두며, 중간 톤 섹션은 최대 하나이고 메인 배경으로는 쓰지 않습니다.
- 배경은 섹션 경계에서 큰 덩어리로 바뀝니다. `.wrap`이나 래퍼에서 바꾸지 않고, 섹션 사이에 border-top이나 구분선을 두지 않으며, 섹션 안에 띠(자기만의 배경으로 제목을 담은, 폭 80% 이상의 상자)를 두지 않고, 배경을 대신하는 안쪽 색 상자도 두지 않습니다. 시각 요소를 담은 프레임은 괜찮습니다.

## 다른 종류는 평면을 유지합니다

제품, 서비스, 장소(site-kind other): 모든 배경과 패널은 평면 CSS 색이며 사진은 있는 그대로 보여 줍니다. 그라디언트(하드 스톱 투톤 포함), 그레인, 종이, 헤일로, 텍스처, 패턴, 글라스, 등고선, 캔버스, `backdrop-filter`, 그라디언트 마스크, 인터페이스에 얹은 그림자나 틴트는 쓰지 않습니다. 이 종류에는 `pick.mjs`를 돌리지 않습니다. `index.json`이 제품, 서비스, 장소의 배경도 나열하지만 쓰지 않습니다. site-kind가 tech인 제품 페이지는 테크로 뽑습니다.

## 테크: CSS 배경

`assets/backgrounds`에 CSS로 그린(WebGL 없음) 배경 열여섯 가지가 있습니다. `system.css`와 `cards.css` 뒤에 `backgrounds.css`를 링크하고, `<head>` 끝에서 `backgrounds.js`를 일반 스크립트로 불러옵니다. 섹션이나 히어로의 래퍼에 클래스 하나를 붙입니다(`<section class="section bg-halo">`). `stage`는 시각 카드 하나를 감싸는 `<div class="bg-stage">`로만 쓰고, `paper`는 `<body>`에, `topglow`는 내비게이션과 히어로를 감싸는 곳에 붙이며 둘은 토큰을 설정하지 않습니다. 나머지 열세 가지 섹션 배경은 페이지 토큰을 설정하므로 카드와 버튼이 그대로 동작합니다. 잉크는 모든 팔레트에서 7:1, 뮤트는 4.5:1을 유지합니다(`check.mjs`가 측정합니다). `index.json`에 각 배경의 분위기, 역할, 짝, 피할 것, 섹션이 들어 있습니다.

- **Soft:** `mist` 색 번짐, `halo` 제목 뒤의 빛, `ruled` 컨테이너 가장자리의 가는 격자(제목 뒤는 비움), `dots` 여백의 점, `arcs` 솟아오르는 고리(마무리 섹션용), `liquid` 색 타원이 천천히 섞이는 메시이며 움직이는 유일한 배경입니다.
- **Hard:** `grain` 필름 그레인이 든 틴트, `dusk` 페이지로 녹아드는 한 톤, `band` 밝은 배경의 두 번째 톤, `field` 그레인 낀 그라디언트(Figma의 샌드 타일), `photo` 사진 레이어, `horizon` 밝은 테두리가 있는 어두운 띠, `deep` 차가운 웅덩이가 있는 거의 검정(x.ai의 것).
- **뽑기:**

  ```bash
  node <skill>/assets/backgrounds/pick.mjs --type software --sections <the plan's ids> --mode light|dark --history .taste-skill/bg-history.json
  ```

  하드웨어는 `--type product --kind tech`로 돌립니다. 효과나 장면을 이미 뽑았다면 `--effect`를 더하고, 그것을 담은 섹션(효과 히어로, `[data-visual]` 섹션, 장면의 섹션)은 `--sections`에서 뺍니다. 그 섹션은 자기 배경을 가져옵니다.

  리듬상 이미 띠가 되는 섹션은 `id:dark`, `id:band`(밝은 배경), `id:surface`로 표시합니다. 출력된 대로 만든 뒤 규칙을 지킵니다. 토큰 외에 뽑은 배경은 페이지당 최대 둘이고 각각 한 번만 쓰며, 카드에는 쓰지 않고, 강한 것 둘을 이웃하게 두지 않고, 시끄러운 것은 최대 하나, 서로 `avoids`에 나열된 둘은 함께 쓰지 않습니다.
- **효과 규칙:** 그레인, 디더, 텍스처(`grain`, `field`, `stage`, `deep`)나 움직임(`liquid`)이 있는 배경은 페이지의 단 하나뿐인 효과입니다(`effects-usage.md`). 다른 효과를 이미 뽑았다면 이것들을 빼고 다시 뽑습니다. `liquid`는 로드 시점부터 시계를 따라 돌며 일시정지 원반이 있고, 모션 감소 설정에서는 멈춥니다.
- **밝은 배경**(`<html data-ground="sand|sky|sage|painting">`)은 테크 전용입니다. UI 뒤, 마무리 띠, `footer-statement`에 쓰며 `band`와 `field`의 톤입니다.
- **`photo` 위의 글자**는 사진의 고요하고 어두운 부분(`--g-photo-pos`, 피사체는 `--g-photo-pos-m`)에 놓습니다. 히어로와 마무리 띠 하나에만 씁니다(`system.md`).
- **조정:** `--g-hue` 틴트, `--g-k` 강도, `--tone` 두 번째 톤, `--halo-x`/`--halo-y`, `--stage-w`. 틴트는 강조색 쪽으로 기울이고 보라색은 안 됩니다.
- 배경은 섹션의 높이를 바꾸지 않습니다(`layout-v4.md`). 부드러운 것은 120px에 걸쳐 사라지고, 단단한 것은 상자 전체에서 색을 유지합니다. 패널은 `.wrap` 선에 맞춰 `bg-inset`을 씁니다.

## 테크: 코드로 그린 배경의 모습

스튜디오 사진처럼 고요하고 구체적입니다. 빛 하나, 팔레트 하나, 가까이서만 눈에 띄는 그레인입니다. 색은 토큰(`--ground`, `--ground-2`, `--ink`, `--tone`, `--tone-hi` = L +0.12, `--tone-lo` = L -0.18)에서 OKLCH로 섞고 배경 채도는 0.12 미만으로 합니다. 그라디언트는 빛부터 만듭니다. 한 색조에서 네 개에서 여섯 개의 스톱을 가진 방사형을 만들고 그레인(4~10%)을 얹습니다. 어두운 그라디언트에는 모두 정적 디더를 입힙니다. 두 스톱짜리 선형 그라디언트를 장식으로 쓰지 않습니다(선형은 시각 요소 안의 가장자리 페이드로만). 투톤 이음매는 하드 스톱입니다. 그레인은 단 하나의 효과 안에서만 쓰며 로드 시 만든 타일 하나로 하고, 애니메이션하지 않으며 UI, 글자, 사진 위에는 얹지 않습니다. 레시피는 모두 정지 상태입니다.

- **조명 스튜디오 스윕:** 누끼 이미지나 UI 창 뒤. 타원 방사형(50~60% x 40~50%, 중심은 35~42% 아래), 희미한 바닥 반사, 그레인 4~6%, 부드러운 접촉 그림자.
- **모서리 글로:** 어두운 푸터, 마무리 띠, 가격 카드. 한쪽 모서리 근처의 방사형, 반경 110~130%, 링이 보이지 않도록 완만한 스톱 다섯 개.
- **회화풍 필드:** UI 창이나 마무리 띠 아래. 톤을 띤 큰 타원 네 개에서 여섯 개를 60~120px 흐리게 하고, 10% 크게 그린 뒤 잘라 내고, 그레인을 얹습니다.
- **스포트라이트 바닥:** 하드웨어 무대나 어두운 페이지의 어두운 히어로. 폭 70%의 빛 웅덩이, 물체에서 멀어지는 흐린 그림자, 양쪽 비네트.
- **제품 색 워시:** 하드웨어 카드나 모델 전환. 제품 색조로 아래에서 올라오는 방사형이며 클릭하면 크로스페이드하고 스크롤에는 반응하지 않습니다.
- **직조 타일과 정렬 디더:** 페이지당 텍스처는 최대 하나. 띠, 푸터, 기술 패널.
- **그리드 마크**(열 교차점의 점이나 더하기 기호, 잉크 12~18%)는 어두운 기술 띠 하나, 데이터 패널, 푸터에만 쓰고 글자 위에는 두지 않습니다. 헤어라인 원장(헤더 셀, 라인업, 푸터 프레임)은 잉크 12~15%의 1px 반복 형제 선이며 섹션 사이에는 두지 않습니다.
