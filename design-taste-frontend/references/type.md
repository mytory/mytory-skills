# 타이포그래피

방문자가 보는 것의 대부분은 글자이며, 페이지가 설계됐는지 조립됐는지를 주로 결정합니다. 방향 시트는 서체·굵기·설정으로 구성된 타이포그래피 체계를 제공합니다. 이 문서는 그 사용법입니다.

## 목차

1. 연구에서 측정한 것
2. 크기 체계: 적은 종류, 큰 차이
3. 큰 글자 조판
4. 본문 조판
5. 글꼴을 제대로 불러오기
6. 글꼴 하나 또는 둘
7. 조판과 단순 입력을 가르는 세부 사항
8. 검사기가 보지 못하는 실수

## 1. 연구에서 측정한 것

조사한 247개 중 측정 가능한 202개 사이트 기준입니다(Chrome, 1440×900 및 390×844).

| 항목 | 중앙값 | 가운데 절반 | 참고 |
| --- | --- | --- | --- |
| 히어로 헤드라인 크기 | 72px (5.0vw) | 43–109px | 상위 사이트 중앙값 6.0vw |
| 페이지의 가장 큰 글자 | 6.4vw | 최대 10.4vw | 상위 8.4vw, 하위 5.0vw |
| 휴대폰 히어로 헤드라인 | 40px | 32–59px | |
| 히어로 자간 | -0.01em | -0.03–0 | 커질수록 좁게 |
| 히어로 행간 | 1.0 | 0.95–1.1 | |
| 본문 크기 | 16px | 14–18px | |
| 헤드라인 ÷ 본문 크기 | 4.3 | | 상위 사이트 4.7 |
| 실제 사용 서체 수 | 2 | 하나 31%, 둘 45%, 셋 22% | |
| 히어로 굵기 | regular 48%, medium 18%, bold 이상 22% | | 큰 글자가 꼭 굵을 필요는 없음 |
| 히어로 대문자 | 24% | | |
| 히어로 가운데 정렬 | 39% | | 하위 사이트 52% |

여기서 두 가지를 취하세요. 첫째, 크기 대비가 핵심 수단이며 좋은 사이트는 더 과감하게 씁니다. 둘째, 굵기는 그렇지 않습니다. 히어로 절반은 regular입니다. 크기와 간격이 자신감을 만들고 bold는 여러 선택지 중 하나입니다.

## 2. 크기 체계: 적은 종류, 큰 차이

패널은 상위 114개 중 약 30개가 중간 크기 없이 두세 가지 크기만 쓴다고 기록했고, 다섯·여섯 단계의 점진적 체계를 쓴다는 기록은 없었습니다. 큰 제목·본문·작은 글자 하나씩이면 페이지를 지탱합니다. 필요할 때 도입문과 섹션 제목 크기를 추가하되 최대 다섯 가지입니다. 서로 비슷한 아홉 크기(16, 18, 20, 24, 28, 32…)는 흐릿하게 느껴집니다. 뚜렷이 다른 단계를 고르세요.

```css
:root {
  --step-small: clamp(0.8125rem, 0.79rem + 0.1vw, 0.875rem);   /* 13–14px 캡션, 법적 문구 */
  --step-body:  clamp(1.0625rem, 1rem + 0.25vw, 1.1875rem);    /* 17–19px 본문 */
  --step-lead:  clamp(1.25rem, 1.1rem + 0.7vw, 1.625rem);      /* 20–26px 보조 문장, 큰 본문 */
  --step-head:  clamp(2rem, 1.3rem + 3.2vw, 4rem);             /* 32–64px 섹션 제목 */
  --step-display: clamp(3rem, 1rem + 9vw, 9rem);               /* 히어로 설계에서 지정 */
}
```

- `--step-display`는 방향에 속합니다. 기념비 같은 워드마크는 16–24vw, 조용한 도구의 헤드라인은 28px입니다. 히어로 설계의 크기를 따르되 뷰포트에 따라 변하고 휴대폰과 초광폭 화면에서 제한되는 `clamp()`를 쓰세요.
- 간극을 유지하세요. 데스크톱 큰 제목은 본문의 최소 네 배여야 합니다. 여섯 번째 크기가 실제로 필요한 경우 외에는 `--step-lead`와 `--step-head` 사이에 새 크기를 넣지 마세요.
- 카드와 라벨마다 ‘소제목’ 크기를 추가하지 마세요. 거의 같아 보이는 두 크기는 하나로 합치세요.

## 3. 큰 글자 조판

큰 글자에서는 본문 크기에 보이지 않던 간격 문제가 드러납니다. 40px 초과 요소에 다음을 적용하세요.

```css
.display {
  font-size: var(--step-display);
  line-height: 0.95;              /* 0.85–1.05; 대문자와 좁은 서체는 더 촘촘하게 */
  letter-spacing: -0.035em;       /* -0.02–-0.05em; 방향 시트 값 사용 */
  font-kerning: normal;
  text-wrap: balance;
  max-width: 14ch;                /* 원하는 위치에서 줄바꿈되도록 폭 선택 */
  margin: 0;
}
```

- **자간은 크기에 따라 조정합니다.** 클수록 좁혀야 합니다. 120px에 맞는 값은 32px를 답답하게 합니다. 모든 제목에 한 번 지정하지 말고 크기 단계별로 정하세요.
- **1.0 미만 행간은 확인해야 합니다.** 아래로 내려오는 획이 다음 줄의 위로 올라오는 획·악센트와 충돌하는지 보세요. 두 줄 제목이면 눈으로 쉽게 확인됩니다.
- **전체 대문자**는 큰 크기여도 자간을 약간 열고(0–+0.03em) 행간은 약 0.9로 둡니다.
- **시각적 정렬.** 왼쪽이 둥글거나 대각선인 큰 글자(O, C, A, T, W)는 들여쓴 듯 보입니다. 헤드라인을 약 0.04–0.06em 왼쪽으로 당겨(`margin-left: -0.05em`) 아래 본문과 시각적으로 맞추세요.
- **화면 폭을 채우는 글자.** `vw`로 크기를 정하고 390과 1440에서 확인하세요. `white-space: nowrap`으로 줄바꿈 대신 컨테이너에서 잘리게 합니다. 글자 수로 계산하세요. `font-size ≈ container width ÷ (characters × k)`, k는 `copy.md` §2를 참조합니다.
- 큰 글자에 그림자·외곽선·그라데이션 채움을 추가하지 마세요.

## 4. 본문 조판

```css
body { font-size: var(--step-body); line-height: 1.5; font-kerning: normal; text-rendering: optimizeLegibility; }
p { max-width: 62ch; text-wrap: pretty; margin: 0; }
p + p { margin-top: 0.9em; }
.lead { font-size: var(--step-lead); line-height: 1.35; max-width: 40ch; }
small, .caption { font-size: var(--step-small); line-height: 1.45; }
```

- 한 줄 길이: 45–75자. 더 길면 다음 줄을 찾기 어렵습니다. 검사기는 약 88자를 넘으면 경고합니다.
- 행간: 본문 1.45–1.6, 큰 도입문은 더 촘촘한 1.3–1.4, 장문 읽기는 더 여유롭게 둡니다.
- 보조 글자는 같은 서체에 부드러운 글자색(`--muted`)을 씁니다. 가벼운 굵기로 바꾸지 않으며 13px 미만으로 줄이지 않습니다.
- 세 줄보다 긴 문단은 가운데 정렬하지 마세요. 양쪽 정렬도 하지 마세요.
- 어두운 바탕의 밝은 글자는 더 굵어 보입니다. 굵기를 한 단계 낮추거나 자간을 0.01em 더하고 행간도 조금 늘리세요.

## 5. 글꼴을 제대로 불러오기

시트의 `<link>`를 그대로 쓰세요. 좋아하는 다른 서체로 바꾸지 마세요.

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="…from the direction sheet…" rel="stylesheet">
```

```css
:root {
  --font-display: "Family From Sheet", "Helvetica Neue", Arial, sans-serif;
  --font-text: "Family From Sheet", Georgia, serif;
}
```

- 실제 쓰는 굵기만 요청하세요(보통 총 두세 가지).
- 같은 큰 분류의 대체 글꼴을 항상 지정하세요(sans에는 sans, serif에는 serif).
- 프레임워크에서는 같은 서체와 굵기를 글꼴 로더로 불러오세요(`next/font/google` 또는 `font-display: swap`을 둔 자체 호스팅 `@font-face`). Fontshare는 시트의 `api.fontshare.com` 스타일시트로 불러옵니다.
- 빌드 뒤 `inspect.mjs`는 실제 렌더링한 글꼴을 보고합니다. 로드 실패 경고가 있으면 스크린샷은 대체 글꼴이며 이를 근거로 한 평가는 유효하지 않습니다. 링크부터 고치세요.

## 6. 글꼴 하나 또는 둘

조사 사이트의 3분의 1은 한 글꼴만 씁니다. 일관성을 얻는 가장 안전한 방법입니다. 제공된 체계가 둘이라면:

- 역할을 고정하세요. 하나는 제목, 다른 하나는 나머지 전부입니다.
- 라벨·숫자·인용문용 세 번째 서체를 추가하지 마세요.
- 한 헤드라인에 두 서체를 섞지 마세요.
- 이탤릭은 작품명과 문단 안의 실제 강조용이며 장식용이 아닙니다.

## 7. 조판과 단순 입력을 가르는 세부 사항

- 곡선 따옴표와 아포스트로피, 올바른 대시와 줄임표(`copy.md` §7).
- 열로 정렬한 가격·표·날짜에는 `font-variant-numeric: tabular-nums`, 세리프 본문에는 `oldstyle-nums`가 어울립니다.
- 링크에는 `text-underline-offset: 0.18em; text-decoration-thickness: 0.07em`을 써서 아래로 내려오는 획과 밑줄이 겹치지 않게 합니다.
- 제목에는 `hyphens: none`. `overflow-wrap: anywhere`는 긴 URL·이메일에만 씁니다.
- 제목은 뒤의 본문에 속합니다. 위 간격은 아래 간격의 최소 두 배입니다.
- `::selection { background: var(--accent); color: var(--accent-ink); }`과 강조색의 눈에 보이는 `:focus-visible` 외곽선으로 브라우저 상태까지 디자인에 포함하세요.
- 호버에서 굵기를 바꾸면 줄이 다시 배치되므로 바꾸지 마세요.

## 8. 검사기가 보지 못하는 실수

- 두 줄 규칙은 통과하지만 두 번째 줄에 한 단어만 남거나 구절이 갈라지는 제목(“Stools for small / kitchens”). 줄바꿈을 직접 지정하세요.
- 획이 닿을 만큼 좁거나 흩어질 만큼 넓은 큰 글자 자간.
- 강한 히어로 뒤에 거의 같은 크기의 섹션 제목. 화면마다 한 크기만 지배하게 하세요.
- 큰 크기 전용으로 그린 서체를 본문에 사용.
- 모두 굵게 표시. 모든 줄을 강조하면 아무것도 강조되지 않습니다.
