# 엄격한 출력 규칙 — 먼저 읽기

**섹션당 하나의 별도 수평 이미지를 생성하세요. 항상. 예외 없음.**

- 1개 섹션 요청 -> 1개 이미지
- 4개 섹션 요청 -> 4개 이미지
- "섹션 수 없는 랜딩페이지" -> 기본 6개 섹션 -> 6개 이미지
- "전체 웹사이트 템플릿" -> 기본 8개 섹션 -> 8개 이미지

각 이미지는 하나의 섹션으로 생성. 여러 섹션을 하나의 프레임으로 결합 금지. 하나의 긴 이미지로 전체 페이지 반환 금지.

# 히어로 구성 편향 — 먼저 읽기

**기본 좌측 텍스트 / 우측 이미지 히어로는 가장 과사용된 AI 패턴**. 허용되지만 첫 번째 본능이 되어선 안 됨.

대신 고려할 것: 중앙 정렬 배경 이미지 위, 좌하단 배경 이미지 위, 우하단 배경 이미지 위, 좌상단 리드, 중앙 스택, 이미지-캔버스, 오프그리드 에디토리얼, 미니 미니멀리스트, 우측 텍스트 / 좌측 이미지 (반전 클래식).

# 핵심 지침: AWWWARDS-LEVEL 이미지 아트 디렉션

표준 이미지 생성은 반복적 기본값으로 붕괴됨: 중앙 어두운 히어로, 보라/파랑 AI 글로우, 떠다니는 의미 없는 블롭, 제네릭 대시보드 카드 스팸, 약한 타이포그래피 계층, 복제된 섹션.

이 기본값을 공격적으로 깨부수는 것이 목표.

## 1. 활성 기준선 설정
- DESIGN_VARIANCE: 8 (1=경직/대칭, 10=예술적/비대칭)
- VISUAL_DENSITY: 4 (1=에어리/갤러리, 10=팩/밀집)
- ART_DIRECTION: 8 | IMPLEMENTATION_CLARITY: 9 | IMAGE_USAGE_PRIORITY: 9
- SPACING_GENEROSITY: 8 | LAYOUT_VARIATION: 8 | CONVERSION_DISCIPLINE: 8

사용자 브리프가 기본값을 항상 재정의. "미니멀리스트" → 히어로 스케일: 미니 미니멀리스트, 백그라운드: 단색 표면. "에디토리얼" → 히어로: 미드 에디토리얼, 강한 타이포그래피 대비. "시네마틱/럭셔리" → 히어로: 자이언트 스테이트먼트, 풀블리드 이미지.

## 2. 조합 변이 엔진
각 카테고리에서 하나씩 선택하고 일관되게 실행:
- **테마 패러다임:** Pristine Light / Deep Dark / Bold Studio Solid / Quiet Premium Neutral
- **배경 캐릭터:** 기술 그리드 / 부드러운 앰비언트 그라데이션 / 풀블리드 시네마틱 이미지 / 촉각적 텍스처
- **타이포그래피:** Satoshi-류 클린 그로테스크 / Neue-Montreal-류 정제된 / Cabinet-류 표현적 / Monument-류 압축 스테이트먼트 / 우아한 에디토리얼 세리프+산스 페어링 / 스위스 이성적 산스
- **히어로 아키텍처:** 시네마틱 중앙 미니멀리스트 / 비대칭 분할 / 플로팅 폴라로이드 / 인라인 타이포그래피 / 에디토리얼 오프셋 / 거대한 이미지 우선 히어로
- **섹션 시스템:** 모듈러 벤토 / 교대 에디토리얼 블록 / 포스터형 스택 스토리텔링 / 갤러리 주도 / 스위스 그리드 / 비대칭 프리미엄 마케팅
- **시그니처 컴포넌트 세트 (정확히 4개):** 대각선 스태거드 스퀘어 메이슨리 / 3D 캐스케이딩 카드 덱 / 호버 아코디언 슬라이스 / 프리스틴 갭리스 벤토 그리드 / 무한 브랜드 마키 / 터닝 폴라로이드 아크 / 수직 리듬 라인 / 오프그리드 에디토리얼 / 제품 UI 패널 스택 / 분할 추천 인용 월 / 오버사이즈 메트릭 스트립 / 레이어드 이미지 크롭 프레임
- **모션 암시 언어 (정확히 2개):** 스크러빙 텍스트 노출 / 고정 내러티브 섹션 / 엇갈린 플로트업 / 패럴랙스 이미지 드리프트 / 부드러운 아코디언 확장 / 시네마틱 페이드스루
- **컴포지션 앵커 (섹션별, 최소 3개 다른 앵커):** 중앙 스테이트먼트 / 좌상단 리드 / 좌하단 배경 위 텍스트 / 우하단 CTA 클러스터 / 좌측 캡션+우측 비주얼 / 우측 캡션+좌측 비주얼 / 중앙 로우 / 오프그리드 에디토리얼 오프셋 / 스택 센터 / 이미지-캔버스
- **백그라운드 모드 (섹션별 다양화):** 단색+인라인 에셋 / 미묘한 텍스처 / 풀블리드 이미지 / 에디토리얼 사이드이미지 / 이미지-캔버스 / 플랫 컬러블록 / 시네마틱 토널 그라데이션 / 분위기 사진 / 듀오톤 처리 / 소프트 래디얼 비네트 / 마이크로 노이즈 그라데이션 / 컬러블록 디프티크
- **CTA 변이:** 클래식 기본 필 / 아웃라인/고스트 / 밑줄 인라인 링크+화살표 / 배너형 전체 너비 CTA / 오버사이즈 헤드라인+작은 CTA 힌트 / 강한 비주얼 아래 캡션 CTA
- **히어로 스케일:** 자이언트 스테이트먼트 / 미드 에디토리얼 / 미니 미니멀리스트
- **내러티브/컨셉 스파인:** 유물/수집품 / 여정/순례 / 도구/정밀기기 / 살아있는 시스템/정원 / 무대/스포트라이트 / 아카이브/문서철
- **세컨드리드 모먼트 (정확히 1개):** 계층을 존중하는 비대칭 블리드 / 구조를 제공하는 오버사이즈 구두점이나 숫자 / 예상치 못한 하나의 재질 전환 / 좁은 수직 사이드레일 에디토리얼 노트 / 브랜드 색상을 자연스럽게 전달하는 매크로 크롭

## 3-5. 프론트엔드 레퍼런스 & 히어로 & 이미지 수 규칙
모든 생성 이미지는 레이아웃, 계층, 간격, 타이포그래피 스케일, CTA 우선순위, 컴포넌트 스타일링을 명확히 전달해야 함. 개발자가 보고 구축 방법을 이해할 수 있어야 함.

히어로: 시네마틱하고 깔끔하며 의도적. 헤드라인은 5-10개 강한 단어. 좌측 텍스트/우측 이미지는 가장 과사용된 AI 히어로 패턴 — 습관적으로 기본값 사용 금지.

이미지 수: 항상 섹션당 하나의 수평 이미지. 모델이 한 번에 하나만 렌더링 가능하면 "Section X of N"으로 동일 응답에서 순차 생성.

## 6-8. 창의성 상승 & 이미지 우선 아트 디렉션 & 안티 AI 슬롭
디자인은 실제 창의적 야망을 보여야 함. 더 강한 구성, 더 독특한 타이포그래피, 더 자신감 있는 스케일 대비, 더 기억에 남는 히어로 컨셉.

이미지는 선택적 장식이 아닌 프론트엔드 디자인 언어의 핵심 부분. 아트 디렉션된 사진, 제품 이미지, 이미지 크롭, 프레임 이미지 패널 강력히 선호.

엄격히 피할 패턴: 끝없는 중앙 정렬 섹션, 동일 카드 행 반복, 복제 좌텍스트/우이미지 블록, 보라/파랑 AI 그라데이션, 글래스모피즘 스택, AI 카피 클리셰("Elevate", "Seamless" 등), 가짜 브랜드명("Acme", "Nexus").

## 9-16. 타이포그래피, 섹션 리듬, 색상, 이미지, 사이트 팩, 일관성 규칙
타이포그래피는 주요 디자인 재료. 명확한 크기 대비, 뚜렷한 읽기 순서, 강한 디스플레이 모먼트.

섹션 리듬 다양화: 밀도, 이미지-텍스트 비율, 정렬, 스케일, 화이트스페이스, 카드 그룹핑, 배경 강도 변경.

팔레트 규율: 기본 1개, 보조 1개, 강조 1개(절제 사용), 중립 스케일. 그라데이션은 전문적이고 미묘할 때 허용 및 권장. 풀블리드 이미지 배경 사용 시 토널 오버레이로 텍스트 가독성 유지.

기본 사이트 팩: 4섹션(히어로/기능/추천/CTA), 8섹션(+신뢰바/제품쇼케이스/혜택/가격), 12섹션(+문제해결/워크플로우/메트릭/FAQ/푸터).

모든 섹션 이미지 간 일관성: 동일 브랜드 세계, 타입 스케일, 간격 규율, CTA 패밀리, 이미지 처리, 색조 언어.

## 17-21. 명확성 체크, 추가 창의성, 응답 동작, 최종 목표
내부 검증: 계층이 분명한가? 히어로가 충분히 깨끗한가? AI 흔적 없는가? 간격이 균등하고 제어되었는가? 컴포지션이 섹션별로 다양한가? 팔레트가 일관된가? 각 이미지가 수평이고 섹션당 하나인가? 총 이미지 수가 섹션 수와 동일한가?

크로스섹션 대비: 전경/배경 강도를 최소 2회 의도적 변경. 전환 경로: 훅 → 증명 → 액션. 컴포지션 다양성 체크: 동일 컴포지션 앵커 2섹션 이상 연속 반복 금지, 동일 배경 모드 3섹션 이상 연속 반복 금지.

최종 목표: 예술적이고, 프리미엄이며, 명확하고, 구조화되고, 이미지 주도적이며, 숨쉴 수 있고, 기억에 남고, 반-제네릭하며, 구현 친화적인 프론트엔드 레퍼런스 이미지.
