# 프로토콜: 프리미엄 실용적 미니멀리즘 UI 아키텍트

## 1. 프로토콜 개요
이름: 프리미엄 실용적 미니멀리즘 & 에디토리얼 UI
설명: 최고 수준의 워크스페이스 플랫폼과 유사한 고도로 정제된, 울트라 미니멀리스트, "문서 스타일" 웹 인터페이스를 생성하기 위한 고급 프론트엔드 엔지니어링 지침. 이 프로토콜은 고대비 따뜻한 모노크롬 팔레트, 맞춤형 타이포그래피 계층, 세심한 구조적 매크로 화이트스페이스, 벤토 그리드 레이아웃, 그리고 의도적인 차분한 파스텔 강조가 있는 울트라 플랫 컴포넌트 아키텍처를 엄격히 강제합니다. 표준적인 일반 SaaS 디자인 트렌드를 적극적으로 거부합니다.

## 2. 절대적 부정 제약 (금지 요소)
AI는 다음 일반 웹 개발 기본값을 엄격히 피해야 합니다:
- "Inter", "Roboto", "Open Sans" 서체 사용 금지.
- "Lucide", "Feather", 표준 "Heroicons" 같은 일반적인 얇은 라인 아이콘 라이브러리 사용 금지.
- Tailwind의 기본 무거운 드롭 섀도우(예: `shadow-md`, `shadow-lg`, `shadow-xl`) 사용 금지. 그림자는 거의 존재하지 않거나 울트라 확산, 낮은 불투명도(< 0.05)로 크게 커스터마이즈되어야 함.
- 큰 요소나 섹션에 기본 원색 배경 사용 금지(예: 밝은 파랑, 초록, 빨강 히어로 섹션 금지).
- 그라데이션, 네온 컬러, 3D 글래스모피즘 사용 금지(미묘한 내비바 블러 제외).
- 큰 컨테이너, 카드, 기본 버튼에 `rounded-full`(필 모양) 사용 금지.
- 코드, 마크업, 텍스트 콘텐츠, 헤딩, 대체 텍스트 어디에도 이모지 사용 금지. 적절한 아이콘이나 깔끔한 SVG 프리미티브로 대체.
- "John Doe", "Acme Corp", "Lorem Ipsum" 같은 일반적인 플레이스홀더 이름 사용 금지. 현실적이고 맥락에 맞는 콘텐츠 사용.
- AI 카피라이팅 클리셰 사용 금지: "Elevate", "Seamless", "Unleash", "Next-Gen", "Game-changer", "Delve". 평이하고 구체적인 언어로 작성.

## 3. 타이포그래피 아키텍처
인터페이스는 극단적인 타이포그래피 대비와 프리미엄 폰트 선택에 의존하여 에디토리얼 느낌을 확립해야 합니다.
- 기본 산세리프 (본문, UI, 버튼): 개성 있는 깔끔하고 기하학적이거나 시스템 네이티브 폰트 사용. 대상: `font-family: 'SF Pro Display', 'Geist Sans', 'Helvetica Neue', 'Switzer', sans-serif`.
- 에디토리얼 세리프 (히어로 헤딩 & 인용문): 대상: `font-family: 'Lyon Text', 'Newsreader', 'Playfair Display', 'Instrument Serif', serif`. 좁은 트래킹 (`letter-spacing: -0.02em`에서 `-0.04em`)과 좁은 행간 (`1.1`) 적용.
- 고정폭 (코드, 키스트로크, 메타데이터): 대상: `font-family: 'Geist Mono', 'SF Mono', 'JetBrains Mono', monospace`.
- 텍스트 색상: 본문 텍스트는 절대 순수 검정(`#000000`)이어선 안 됨. 가독성을 위해 오프블랙/차콜(`#111111` 또는 `#2F3437`)에 넉넉한 `line-height` `1.6` 사용. 보조 텍스트는 차분한 회색(`#787774`).

## 4. 색상 팔레트 (따뜻한 모노크롬 + 스팟 파스텔)
색상은 의미적 용도나 미묘한 강조에만 사용되는 희소 자원입니다.
- 캔버스 / 배경: 순수 화이트 `#FFFFFF` 또는 따뜻한 본/오프화이트 `#F7F6F3` / `#FBFBFA`.
- 기본 표면 (카드): `#FFFFFF` 또는 `#F9F9F8`.
- 구조적 보더 / 구분선: 울트라 라이트 그레이 `#EAEAEA` 또는 `rgba(0,0,0,0.06)`.
- 강조 색상: 태그, 인라인 코드 배경, 미묘한 아이콘 배경에만 고도로 채도가 낮고 워시아웃된 파스텔 사용.
  - 페일 레드: `#FDEBEC` (텍스트: `#9F2F2D`)
  - 페일 블루: `#E1F3FE` (텍스트: `#1F6C9F`)
  - 페일 그린: `#EDF3EC` (텍스트: `#346538`)
  - 페일 옐로우: `#FBF3DB` (텍스트: `#956400`)

## 5. 컴포넌트 명세
- 벤토 박스 기능 그리드:
  - 비대칭 CSS Grid 레이아웃 활용.
  - 카드는 정확히 `border: 1px solid #EAEAEA`이어야 함.
  - 보더 반경은 깔끔하게: 최대 `8px` 또는 `12px`.
  - 내부 패딩은 넉넉하게 (예: `24px`에서 `40px`).
- 기본 행동 유도 버튼 (CTA):
  - 단색 배경 `#111111`, 텍스트 `#FFFFFF`.
  - 약간의 보더 반경 (`4px`에서 `6px`). 그림자 없음.
  - 호버 상태는 미묘한 색상 이동 `#333333` 또는 마이크로 스케일 `transform: scale(0.98)`.
- 태그 & 상태 배지:
  - 필 모양 (`border-radius: 9999px`), 매우 작은 타이포그래피 (`text-xs`), 넓은 트래킹이 있는 대문자 (`letter-spacing: 0.05em`).
  - 배경은 정의된 뮤트 파스텔을 사용해야 함.
- 아코디언 (FAQ):
  - 모든 컨테이너 박스 제거. `border-bottom: 1px solid #EAEAEA`로만 항목 분리.
  - 토글 상태에 깔끔하고 날카로운 `+` 및 `-` 아이콘 사용.
- 키스트로크 마이크로 UI:
  - `<kbd>` 태그를 사용해 물리적 키로 단축키 렌더링: `border: 1px solid #EAEAEA`, `border-radius: 4px`, `background: #F7F6F3`, 고정폭 폰트 사용.
- 가짜 OS 윈도우 크롬:
  - 소프트웨어를 모킹할 때, macOS 윈도우 컨트롤을 복제한 세 개의 작은 밝은 회색 원이 포함된 흰색 상단 바가 있는 미니멀리스트 컨테이너로 감싸기.

## 6. 아이코노그래피 & 이미지 지침
- 시스템 아이콘: 기술적이고 약간 더 두꺼운 획의 미학을 위해 "Phosphor Icons (Bold 또는 Fill 가중치)" 또는 "Radix UI Icons" 사용. 모든 아이콘에 걸쳐 획 너비 표준화.
- 일러스트레이션: 단색의 거친 연속 선 잉크 스케치, 흰색 배경, 뮤트 파스텔 색상으로 채워진 단일 오프셋 기하학적 도형.
- 사진: 따뜻한 톤의 고품질 탈채도 이미지 사용. 사진을 모노크롬 팔레트에 혼합하기 위해 미묘한 오버레이(`opacity: 0.04` 따뜻한 그레인) 적용. 과채도 스톡 사진 절대 사용 금지. 실제 에셋을 사용할 수 없을 때는 `https://picsum.photos/seed/{context}/1200/800` 같은 신뢰할 수 있는 플레이스홀더 사용.
- 히어로 & 섹션 배경: 섹션이 비어 있고 평평하게 느껴지지 않아야 함. 미묘한 전체 너비 배경 이미지를 매우 낮은 불투명도로, 부드러운 래디얼 라이트 스폿(따뜻한 톤의 `radial-gradient`, `opacity: 0.03`), 또는 미니멀한 기하학적 라인 패턴을 사용해 깔끔한 미학을 깨지 않고 깊이 추가.

## 7. 미묘한 모션 & 마이크로 애니메이션
모션은 보이지 않는 것처럼 느껴져야 합니다 — 존재하지만 결코 방해되지 않음. 목표는 스펙터클이 아닌 조용한 세련미입니다.
- 스크롤 진입: 요소가 뷰포트에 진입할 때 부드럽게 페이드 인. `cubic-bezier(0.16, 1, 0.3, 1)`로 600ms 이상 `translateY(12px)` + `opacity: 0` 해소. `IntersectionObserver` 사용, 절대 `window.addEventListener('scroll')` 금지.
- 호버 상태: 카드는 울트라 미묘한 그림자 이동으로 들어 올리기(`box-shadow`가 `200ms` 이상 `0 0 0`에서 `0 2px 8px rgba(0,0,0,0.04)`로 트랜지션). 버튼은 `:active`에서 `scale(0.98)`로 반응.
- 엇갈린 노출: 리스트와 그리드 항목이 캐스케이드 지연으로 진입 (`animation-delay: calc(var(--index) * 80ms)`). 모든 것을 한 번에 마운트하지 마세요.
- 배경 앰비언트 모션: 선택적. 히어로 섹션 뒤를 표류하는 단일의 매우 느리게 움직이는 래디얼 그라디언트 블롭 (`animation-duration: 20s+`, `opacity: 0.02-0.04`). `position: fixed; pointer-events: none` 레이어에 적용 필수. 스크롤 컨테이너에는 절대 적용 금지.
- 성능: `transform`과 `opacity`로만 애니메이션. 레이아웃 트리거 속성(`top`, `left`, `width`, `height`) 없음. 능동적으로 애니메이션 중인 요소에만 `will-change: transform`을 드물게 사용.

## 8. 실행 프로토콜
프론트엔드 코드(HTML, React, Tailwind, Vue) 작성 또는 레이아웃 설계 시:
1. 매크로 화이트스페이스를 먼저 설정. 섹션 간에 거대한 수직 패딩 사용 (예: Tailwind에서 `py-24` 또는 `py-32`).
2. 주요 타이포그래피 콘텐츠 너비를 `max-w-4xl` 또는 `max-w-5xl`로 제한.
3. 맞춤형 타이포그래피 계층과 모노크로매틱 색상 변수를 즉시 적용.
4. 모든 카드, 구분선, 보더가 `1px solid #EAEAEA` 규칙을 엄격히 준수하는지 확인.
5. 모든 주요 콘텐츠 블록에 스크롤 진입 애니메이션 추가.
6. 이미지, 앰비언트 그라데이션, 미묘한 텍스처를 통해 섹션에 시각적 깊이 부여 — 비어 있는 평평한 배경 없음.
7. 수동 조정 없이 이 하이엔드, 정리된, 에디토리얼 미학을 네이티브로 반영하는 코드 제공.
