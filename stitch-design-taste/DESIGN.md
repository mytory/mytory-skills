## 설정 — 스타일 지정
이 디자인 시스템을 사용하기 전에 이 다이얼을 조정하세요. 출력의 창의성, 밀도, 애니메이션 정도를 제어합니다. 프로젝트에 맞는 레벨 선택.

| 다이얼 | 레벨 | 설명 |
|------|-------|-------------|
| **창의성** | `8` | `1` = 울트라 미니멀, 스위스, 조용, 모노크롬. `5` = 밸런스, 깔끔하지만 개성 있음. `10` = 표현적, 에디토리얼, 대담한 타이포그래피 실험, 헤드라인에 인라인 이미지, 강한 비대칭. 기본값: `8` |
| **밀도** | `4` | `1` = 갤러리 에어리, 거대한 화이트스페이스. `5` = 균형 잡힌 섹션. `10` = 칵핏 밀집, 데이터 중심. 기본값: `4` |
| **변이** | `8` | `1` = 예측 가능, 대칭 그리드. `5` = 미묘한 오프셋. `10` = 예술적 혼돈, 같은 섹션 없음. 기본값: `8` |
| **모션 의도** | `6` | `1` = 정적, 애니메이션 언급 없음. `5` = 미묘한 호버/진입 신호. `10` = 모든 컴포넌트에 시네마틱 오케스트레이션. 기본값: `6` |

> **사용법:** 위 숫자를 프로젝트 분위기에 맞게 변경. **창의성 1–3**에서 시스템은 깔끔하고 조용한 Notion 같은 인터페이스 생성. **창의성 7–10**에서는 인라인 이미지 타이포그래피, 극적 스케일 대비, 강한 에디토리얼 레이아웃 기대. 아래 규칙들은 선택한 레벨에 적응.

## 1. 시각적 테마 & 분위기
확신 있는 비대칭 레이아웃과 유체 스프링 물리 모션이 있는 절제된 갤러리 에어리 인터페이스. 분위기는 임상적이면서도 따뜻함 — 모든 요소가 기능을 통해 자리를 얻는 조명 좋은 건축 스튜디오처럼. 밀도는 균형(레벨 4), 변이는 높음(레벨 8)으로 대칭적 지루함 방지, 모션은 유체적이지만 연극적이지 않음(레벨 6). 전체적 인상: 비싸고, 의도적이며, 살아있음.

## 2. 색상 팔레트 & 역할
- **캔버스 화이트** (#F9FAFB) — 기본 배경 표면. 따뜻한 중립, 절대 임상적 청백색 아님
- **순수 표면** (#FFFFFF) — 카드 및 컨테이너 채우기. 상승을 위한 위스퍼 그림자와 함께 사용
- **차콜 잉크** (#18181B) — 기본 텍스트. Zinc-950 깊이 — 절대 순수 검정 아님
- **스틸 보조** (#71717A) — 본문 텍스트, 설명, 메타데이터. Zinc-500 온기
- **뮤트 슬레이트** (#94A3B8) — 3차 텍스트, 타임스탬프, 비활성 상태
- **위스퍼 보더** (rgba(226,232,240,0.5)) — 카드 보더, 구조적 1px 라인. 깊이를 위한 반투명
- **확산 그림자** (rgba(0,0,0,0.05)) — 카드 상승. 넓게 퍼짐, 40px 블러, -15px 오프셋. 절대 거칠지 않음

### 강조색 선택 (프로젝트당 하나 선택)
- **에메랄드 시그널** (#10B981) — 성장, 성공, 긍정적 데이터 대시보드
- **일렉트릭 블루** (#3B82F6) — 생산성, SaaS, 개발자 도구
- **딥 로즈** (#E11D48) — 창의적, 에디토리얼, 패션 인접 프로젝트
- **엠버 웜스** (#F59E0B) — 커뮤니티, 소셜, 따뜻한 톤 제품

### 금지 색상
- 보라/바이올렛 네온 그라데이션 — "AI 퍼플" 미학
- 순수 검정 (#000000) — 항상 오프블랙 또는 Zinc-950
- 80% 이상 채도의 과채도 강조색
- 한 프로젝트 내 혼합된 웜/쿨 그레이 시스템

## 3. 타이포그래피 규칙
- **디스플레이:** `Geist`, `Satoshi`, `Cabinet Grotesk`, `Outfit` — 좁은 트래킹(`-0.025em`), 제어된 유체 스케일, 굵기 주도 계층(700–900). 소리치지 않음. 리딩 압축(`1.1`). 대안 강제 — 프리미엄 컨텍스트에서 `Inter` 금지
- **본문:** 굵기 400의 동일 패밀리 — 여유 리딩(`1.65`), 65ch 최대 너비, 스틸 보조 색상(#71717A)
- **모노:** `Geist Mono` 또는 `JetBrains Mono` — 코드 블록, 메타데이터, 타임스탬프. 밀도가 레벨 7 초과 시 모든 숫자 고정폭 전환
- **스케일:** 디스플레이 `clamp(2.25rem, 5vw, 3.75rem)`. 본문 `1rem/1.125rem`. 모노 메타데이터 `0.8125rem`

### 금지 폰트
- `Inter` — 프리미엄/창의적 컨텍스트 어디에서나 금지
- 일반 세리프 폰트(`Times New Roman`, `Georgia`, `Garamond`, `Palatino`) — 금지. 에디토리얼/창의적에 세리프가 필요하면 `Fraunces`, `Gambarino`, `Editorial New`, `Instrument Serif`만 사용. 기본 브라우저 세리프 스택 절대 사용 금지. 세리프는 대시보드나 소프트웨어 UI에서 항상 금지

## 4. 컴포넌트 스타일링
* **버튼:** 플랫 표면, 외부 글로우 없음. 기본: 흰색 텍스트에 강조색 채우기. 보조: 고스트/아웃라인. 액티브 상태: 촉각적 누름을 위한 `-1px translateY` 또는 `scale(0.98)`. 호버: 미묘한 배경 이동, 절대 글로우 아님
* **카드/컨테이너:** 넉넉하게 둥근 모서리(`2.5rem`). 순수 화이트 채우기. 위스퍼 보더(`1px`, 반투명). 확산 그림자(`0 20px 40px -15px rgba(0,0,0,0.05)`). 내부 패딩 `2rem–2.5rem`. 상승이 계층을 전달할 때만 사용 — 고밀도 레이아웃은 카드를 `border-top` 구분선이나 여백으로 대체
* **입력/폼:** 라벨은 입력 위에 위치. 도움말 텍스트 선택. 오류 텍스트는 아래에 딥 로즈로. 포커스 링은 강조색, `2px` 오프셋. 플로팅 라벨 없음. 라벨-입력-오류 스택 간 표준 `0.5rem` 간격
* **내비게이션:** 매끄럽고 고정. 호버 시 아이콘 스케일(Dock 확대 선택). 데스크톱에서 햄버거 없음. 넉넉한 간격의 깔끔한 수평
* **로더:** 정확한 레이아웃 치수와 둥근 모서리와 일치하는 스켈레톤 쉬머. 플레이스홀더 모양 위 이동하는 빛 반사. 절대 원형 스피너 아님
* **빈 상태:** 안내 텍스트가 있는 구성된 일러스트 또는 아이콘 컴포지션. 절대 "데이터 없음"만
* **오류 상태:** 인라인, 컨텍스트적. 빨간 강조 언더라인 또는 보더. 명확한 복구 액션

## 5. 히어로 섹션
히어로는 첫인상 — 강렬하고 창의적이며 절대 제네릭이어선 안 됨.
- **인라인 이미지 타이포그래피:** 헤드라인 단어나 글자 사이에 직접 작은 맥락적 사진이나 비주얼 임베드. 예: "우리는 [타이핑하는 손 사진] 디지털 [화면 사진] 제품을 만듭니다" — 이미지는 타입 높이에 인라인, 둥글게, 단어 사이 시각적 구두점 역할. 시그니처 창의적 기술
- **겹침 요소 금지:** 텍스트가 이미지나 다른 텍스트와 절대 겹치면 안 됨. 모든 요소는 자체 명확한 공간 영역. 콘텐츠 레이어의 z-index 스태킹 없음, 이미지 위 절대 위치 헤드라인 없음. 항상 깨끗한 분리
- **필러 텍스트 금지:** "스크롤하여 탐색", "아래로 스와이프", 스크롤 화살표 아이콘, 바운싱 셰브론, 모든 안내적 UI 크롬 금지. 사용자는 스크롤 방법을 앎. 콘텐츠가 자연스럽게 끌어들이게
- **비대칭 구조:** 이 변이 레벨에서 중앙 정렬 히어로 레이아웃 금지. 분할 화면(50/50), 좌측 정렬 텍스트 / 우측 비주얼, 거대한 빈 영역의 비대칭 화이트스페이스 사용
- **CTA 절제:** 최대 하나의 기본 CTA 버튼. 보조 "더 알아보기" 링크 없음. 헤드라인 아래 중복 마이크로 카피 없음

## 6. 레이아웃 원칙
- **그리드 우선:** 모든 구조적 레이아웃에 CSS Grid. flexbox 백분율 계산(`calc(33% - 1rem)` 금지)
- **겹침 금지:** 요소가 서로 절대 겹치면 안 됨. 콘텐츠 위 콘텐츠를 쌓는 절대 위치 레이어 없음. 모든 요소는 자체 그리드 셀이나 흐름 위치 점유. 깨끗하고 분리된 공간 영역
- **기능 섹션:** "한 행에 3개 동등 카드" 패턴 금지. 2열 지그재그, 비대칭 벤토 그리드(2fr 1fr 1fr), 수평 스크롤 갤러리 사용
- **제한:** 모든 콘텐츠 `max-width: 1400px` 이내, 중앙 정렬. 넉넉한 수평 패딩(모바일 `1rem`, 태블릿 `2rem`, 데스크톱 `4rem`)
- **전체 높이:** `min-height: 100dvh` 사용 — 절대 `height: 100vh` 사용 금지(iOS Safari 주소창 점프)
- **벤토 아키텍처:** 기능 그리드는 행 1: 3열 | 행 2: 2열(70/30 분할) 사용. 각 타일에 지속적 마이크로 애니메이션 포함

## 7. 반응형 규칙
모든 화면이 모든 뷰포트에서 완벽히 작동해야. **반응형은 선택이 아님 — 하드 요구사항. 모든 단일 요소가 375px, 768px, 1440px에서 테스트되어야 함.**
- **모바일 우선 축소 (< 768px):** 모든 다중 열 레이아웃이 엄격한 단일 열로 축소. `width: 100%`, `padding: 1rem`, `gap: 1.5rem`. 예외 없음
- **수평 스크롤 금지:** 모바일에서 수평 오버플로우는 치명적 실패. 모든 요소가 뷰포트 너비에 맞아야. 수평 스크롤을 유발하는 요소가 있으면 디자인이 깨진 것
- **타이포그래피 스케일링:** 헤드라인은 `clamp()`로 우아하게 축소. 본문 텍스트는 최소 `1rem` 유지. 본문을 `14px` 미만으로 축소 금지. 헤드라인은 375px 화면에서도 가독성 유지
- **터치 타겟:** 모든 인터랙티브 요소 최소 `44px` 탭 타겟. 클릭 가능 항목 간 넉넉한 간격. 버튼은 모바일에서 전체 너비
- **이미지 동작:** 히어로 및 인라인 이미지는 비례 축소. 인라인 타이포그래피 이미지(단어 사이 사진)는 모바일에서 인라인 대신 헤드라인 아래로 스택
- **내비게이션:** 데스크톱 수평 nav는 깔끔한 모바일 메뉴로 축소(슬라이드인 또는 전체 화면 오버레이). 라벨 없는 작은 햄버거 아이콘 금지
- **카드 & 그리드:** 벤토 그리드와 비대칭 레이아웃은 전체 너비의 스택된 단일 열 카드로 되돌림. 내부 패딩 유지(`1rem`)
- **간격 일관성:** 수직 섹션 간격은 모바일에서 비례 축소(`clamp(3rem, 8vw, 6rem)`). 절대 비좁지도, 지나치게 에어리하지도 않게
- **테스트 뷰포트:** 디자인은 `375px` (iPhone SE), `390px` (iPhone 14), `768px` (iPad), `1024px` (작은 노트북), `1440px` (데스크톱)에서 검증 필수

## 8. 모션 & 인터랙션 (코드 단계 의도)
> **참고:** Stitch는 정적 화면 생성 — 애니메이션 불가. 이 섹션은 코딩 에이전트(Antigravity, Cursor 등)가 내보낸 디자인을 실제 제품으로 빌드할 때 애니메이션을 정확히 구현할 수 있도록 **의도된 모션 동작**을 문서화.

- **물리 엔진:** 독점적 스프링 기반. `stiffness: 100, damping: 20`. 어디에도 선형 이징 없음. 모든 인터랙티브 요소에 프리미엄 무게감
- **지속적 마이크로 루프:** 모든 활성 대시보드 컴포넌트는 무한 루프 상태 — 상태 점에 Pulse, 검색 바에 Typewriter, 기능 아이콘에 Float, 로딩 상태에 Shimmer
- **엇갈린 오케스트레이션:** 리스트와 그리드는 캐스케이드 지연으로 마운트(`animation-delay: calc(var(--index) * 100ms)`). 워터폴 노출, 절대 즉시 마운트 아님
- **레이아웃 트랜지션:** 공유 요소 ID를 통한 부드러운 재정렬. 물리로 항목 위치 교체, 실시간 지능 시뮬레이션
- **하드웨어 규칙:** `transform`과 `opacity`로만 애니메이션. 절대 `top`, `left`, `width`, `height` 아님. 그레인/노이즈 필터는 고정 pointer-events-none 의사 요소에만
- **성능:** CPU 집약적 지속 애니메이션은 미세 리프 컴포넌트에 격리. 부모 재렌더링 트리거 금지. 최소 60fps 목표

## 9. 안티패턴 (금지)
- UI, 코드, 대체 텍스트 어디에도 이모지 금지
- `Inter` 폰트 금지 — `Geist`, `Outfit`, `Cabinet Grotesk`, `Satoshi` 사용
- 일반 세리프 폰트(`Times New Roman`, `Georgia`, `Garamond`) 금지 — 세리프가 필요하면 독특한 현대 세리프만(`Fraunces`, `Instrument Serif`)
- 순수 검정(`#000000`) 금지 — 오프블랙 또는 Zinc-950만
- 네온 외부 글로우 또는 기본 box-shadow 글로우 금지
