# Stitch Design Taste — 시맨틱 디자인 시스템 스킬

## 개요
이 스킬은 Google Stitch 화면 생성에 최적화된 `DESIGN.md` 파일을 생성합니다. 전투로 검증된 반-슬롭 프론트엔드 엔지니어링 지침을 Stitch의 네이티브 시맨틱 디자인 언어 — Stitch의 AI 에이전트가 프리미엄, 비-제네릭 인터페이스를 생성하기 위해 해석할 수 있는 설명적 자연어 규칙과 정밀한 값의 조합 — 로 변환합니다.

생성된 `DESIGN.md`는 Stitch가 큐레이션된 고-에이전시 디자인 언어에 맞춰 새 화면을 생성하도록 프롬프팅하는 **단일 진실 공급원** 역할을 합니다. Stitch는 특정 색상 값, 타이포그래피 명세, 컴포넌트 동작으로 지원되는 **"시각적 설명"**을 통해 디자인을 해석합니다.

## 전제 조건
- [labs.google.com/stitch](https://labs.google.com/stitch)를 통한 Google Stitch 접근
- 선택: Cursor, Antigravity, Gemini CLI와의 프로그래밍적 통합을 위한 Stitch MCP 서버

## 목표
다음을 인코딩하는 `DESIGN.md` 파일 생성:
1. **시각적 분위기** — 무드, 밀도, 디자인 철학
2. **색상 보정** — 헥스 코드가 있는 중립색, 강조색, 금지 패턴
3. **타이포그래피 아키텍처** — 폰트 스택, 스케일 계층, 안티패턴
4. **컴포넌트 동작** — 인터랙션 상태가 있는 버튼, 카드, 입력
5. **레이아웃 원칙** — 그리드 시스템, 간격 철학, 반응형 전략
6. **모션 철학** — 애니메이션 엔진 명세, 스프링 물리, 지속적 마이크로 인터랙션
7. **안티패턴** — 금지된 AI 디자인 클리셰의 명시적 목록

## 분석 & 종합 지침

### 1. 분위기 정의
대상 프로젝트의 의도 평가. 테이스트 스펙트럼의 연상적 형용사 사용:
- **밀도:** "아트 갤러리 에어리" (1–3) → "일상 앱 밸런스" (4–7) → "칵핏 밀집" (8–10)
- **변이:** "예측 가능 대칭" (1–3) → "오프셋 비대칭" (4–7) → "예술적 혼돈" (8–10)
- **모션:** "정적 절제" (1–3) → "유체 CSS" (4–7) → "시네마틱 안무" (8–10)

기본 기준선: 변이 8, 모션 6, 밀도 4. 사용자의 분위기 설명에 따라 동적 조정.

### 2. 색상 팔레트 매핑
각 색상에 제공: **설명적 이름** + **헥스 코드** + **기능적 역할**.

**필수 제약:**
- 최대 1개의 강조색. 채도 80% 미만
- "AI 보라/파랑 네온" 미학 엄격히 금지 — 보라 버튼 글로우, 네온 그라데이션 금지
- 절대 중립 베이스(Zinc/Slate)에 고대비 단일 강조색 사용
- 전체 출력에 하나의 팔레트 고수 — 따뜻한/차가운 회색 변동 금지
- 순수 검정(`#000000`) 절대 사용 금지 — 오프블랙, Zinc-950, 차콜 사용

### 3. 타이포그래피 규칙 수립
- **디스플레이/헤드라인:** 좁은 트래킹, 제어된 스케일. 소리치지 않음. 거대한 크기가 아닌 굵기와 색상으로 계층.
- **본문:** 여유 있는 리딩, 줄당 최대 65자
- **폰트 선택:** `Inter`는 프리미엄/창의적 컨텍스트에서 금지. 독특한 개성 강제: `Geist`, `Outfit`, `Cabinet Grotesk`, `Satoshi`
- **세리프 금지:** 일반 세리프 폰트(`Times New Roman`, `Georgia`, `Garamond`, `Palatino`)는 금지. 에디토리얼/창의적 컨텍스트에 세리프가 필요하면 독특한 현대적 세리프만 사용: `Fraunces`, `Gambarino`, `Editorial New`, `Instrument Serif`. 대시보드나 소프트웨어 UI에서는 세리프 항상 금지
- **대시보드 제약:** 산세리프 페어링만 사용 (`Geist` + `Geist Mono` 또는 `Satoshi` + `JetBrains Mono`)
- **고밀도 오버라이드:** 밀도가 7을 초과하면 모든 숫자는 고정폭 사용 필수

### 4. 히어로 섹션 정의
히어로는 첫인상이며 창의적이고 강렬해야 하며 절대 제네릭이어선 안 됨:
- **인라인 이미지 타이포그래피:** 헤드라인 단어나 글자 사이에 직접 작은 맥락적 사진이나 비주얼 임베드. 이미지는 타입 높이에 인라인으로, 둥글게, 시각적 구두점 역할. 이것이 시그니처 창의적 기술
- **겹침 금지:** 텍스트가 이미지나 다른 텍스트와 절대 겹치면 안 됨. 각 요소는 자체 깨끗한 공간 영역 점유
- **필러 텍스트 금지:** "Scroll to explore", "Swipe down", 스크롤 화살표 아이콘, 바운싱 셰브론 금지. 콘텐츠가 자연스럽게 사용자를 끌어들여야 함
- **비대칭 구조:** 변이가 4를 초과하면 중앙 정렬 히어로 레이아웃 금지
- **CTA 절제:** 최대 하나의 기본 CTA. 보조 "더 알아보기" 링크 없음

### 5. 컴포넌트 스타일링 설명
각 컴포넌트 유형에 대해 모양, 색상, 그림자 깊이, 인터랙션 동작 설명:
- **버튼:** 액티브 상태에서 촉각적 누름 피드백. 네온 외부 글로우 금지. 커스텀 마우스 커서 금지
- **카드:** 상승이 계층을 전달할 때만 사용. 배경 색조로 그림자 틴트. 고밀도 레이아웃에서는 카드를 border-top 구분선이나 여백으로 교체
- **입력/폼:** 입력 위에 라벨, 선택적 도움말 텍스트, 아래에 오류 텍스트. 표준 간격
- **로딩 상태:** 레이아웃 치수와 일치하는 스켈레톤 로더 — 일반 원형 스피너 금지
- **빈 상태:** 데이터를 채우는 방법을 나타내는 구성된 컴포지션
- **오류 상태:** 명확한 인라인 오류 보고

### 6. 레이아웃 원칙 정의
- 겹치는 요소 금지 — 각 요소는 자체 명확한 공간 영역 점유. 절대 위치 콘텐츠 스태킹 금지
- 변이가 4를 초과하면 중앙 정렬 히어로 섹션 금지 — 분할 화면, 왼쪽 정렬, 비대칭 화이트스페이스 강제
- 제네릭 "3개 동등 카드 수평" 기능 행 금지 — 2열 지그재그, 비대칭 그리드, 수평 스크롤 사용
- Flexbox 수학보다 CSS Grid — `calc()` 백분율 해킹 절대 사용 금지
- max-width 제약으로 레이아웃 제한 (예: 1400px 중앙)
- 전체 높이 섹션은 `min-h-[100dvh]` 사용 — 절대 `h-screen` 사용 금지 (iOS Safari 치명적 점프)

### 7. 반응형 규칙 정의
모든 디자인은 모든 뷰포트에서 작동해야 함:
- **모바일 우선 축소 (< 768px):** 모든 다중 열 레이아웃은 단일 열로 축소. 예외 없음
- **수평 스크롤 금지:** 모바일에서 수평 오버플로우는 치명적 실패
- **타이포그래피 스케일링:** 헤드라인은 `clamp()`로 스케일. 본문 텍스트 최소 `1rem`/`14px`
- **터치 타겟:** 모든 인터랙티브 요소 최소 `44px` 탭 타겟
- **이미지 동작:** 인라인 타이포그래피 이미지(단어 사이 사진)는 모바일에서 헤드라인 아래로 스택
- **내비게이션:** 데스크톱 수평 nav는 깔끔한 모바일 메뉴로 축소
- **간격:** 수직 섹션 간격 비례 축소 (`clamp(3rem, 8vw, 6rem)`)

### 8. 모션 철학 인코딩
- **스프링 물리 기본값:** `stiffness: 100, damping: 20` — 프리미엄, 무게감 있는 느낌. 선형 이징 없음
- **지속적 마이크로 인터랙션:** 모든 활성 컴포넌트는 무한 루프 상태(Pulse, Typewriter, Float, Shimmer)를 가져야 함
- **엇갈린 오케스트레이션:** 리스트를 즉시 마운트하지 말기 — 워터폴 노출을 위해 캐스케이드 지연 사용
- **성능:** `transform`과 `opacity`로만 애니메이션. `top`, `left`, `width`, `height` 애니메이션 금지. 그레인/노이즈 필터는 고정 의사 요소에만

### 9. 안티패턴 나열 (AI 표시)
DESIGN.md에 명시적 "절대 하지 말 것" 규칙으로 인코딩:
- 이모지 모든 곳에서 금지
- `Inter` 폰트 금지
- 일반 세리프 폰트(`Times New Roman`, `Georgia`, `Garamond`) 금지 — 필요한 경우 독특한 현대적 세리프만
- 순수 검정(`#000000`) 금지
- 네온/외부 글로우 그림자 금지
- 과채도 강조색 금지
- 큰 헤더의 과도한 그라데이션 텍스트 금지
- 커스텀 마우스 커서 금지
- 겹치는 요소 금지 — 항상 깨끗한 공간 분리
- 3열 동등 카드 레이아웃 금지
- 제네릭 이름("John Doe", "Acme", "Nexus") 금지
- 가짜 깔끔한 숫자(`99.99%`, `50%`) 금지
- AI 카피라이팅 클리셰("Elevate", "Seamless", "Unleash", "Next-Gen") 금지
- 필러 UI 텍스트: "Scroll to explore", "Swipe down", 스크롤 화살표, 바운싱 셰브론 금지
- 깨진 Unsplash 링크 금지 — `picsum.photos` 또는 SVG 아바타 사용

## 모범 사례
- **설명적으로:** "짙은 차콜 잉크 (#18181B)" — 단순히 "어두운 텍스트"가 아님
- **기능적으로:** 각 요소가 무엇에 사용되는지 설명
- **일관되게:** 문서 전체에 동일한 용어
- **정밀하게:** 정확한 헥스 코드, rem 값, 괄호 안 픽셀 값 포함
- **주관적으로:** 중립 템플릿이 아님 — 특정 프리미엄 미학 강제

## 성공 팁
1. 분위기부터 시작 — 토큰 상세화 전에 분위기 이해
2. 패턴 찾기 — 일관된 간격, 크기, 스타일링 식별
3. 시맨틱하게 생각 — 외관이 아닌 목적으로 색상 명명
4. 계층 고려 — 시각적 무게가 중요성을 어떻게 전달하는지 문서화
5. 금지 인코딩 — 안티패턴은 규칙 자체만큼 중요
