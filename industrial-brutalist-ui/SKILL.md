# 스킬: 산업 브루탈리즘 & 전술 텔레메트리 UI

## 1. 스킬 메타
**이름:** 산업 브루탈리즘 & 전술 텔레메트리 인터페이스 엔지니어링
**설명:** 20세기 중반 스위스 타이포그래픽 디자인, 산업 제조 매뉴얼, 복고풍 미래주의 항공우주/군사 터미널 인터페이스를 종합하는 웹 인터페이스 설계에 대한 고급 숙련도. 이 분야는 엄격한 모듈러 그리드, 극단적인 타이포그래픽 스케일 대비, 순수 실용적 색상 팔레트, 아날로그 열화(하프톤, CRT 스캔라인, 비트맵 디더링)의 프로그래밍적 시뮬레이션에 대한 절대적 숙달을 요구합니다. 목표는 원시적 기능성, 기계적 정밀성, 높은 데이터 밀도를 투사하는 디지털 환경을 구축하는 것이며, 기존 소비자 UI 패턴을 의도적으로 버립니다.

## 2. 시각적 원형
디자인 시스템은 두 개의 뚜렷하지만 높은 호환성을 가진 시각적 패러다임을 병합하여 작동합니다. **프로젝트당 하나를 선택하고 고수하세요. 동일한 인터페이스 내에서 두 모드를 교대하거나 혼합하지 마세요.**

### 2.1 스위스 산업 프린트
1960년대 기업 아이덴티티 시스템과 중장비 청사진에서 파생.
*   **특성:** 고대비 라이트 모드 (신문지/비표백 인쇄 기재). 모놀리식하고 무거운 산세리프 타이포그래피에 의존. 가시적인 분할선으로 윤곽이 드러난 무자비한 구조적 그리드. 오버사이즈의 뷰포트 블리딩 숫자나 문자로 강조된 공격적이고 비대칭적인 여백 사용. 경고/강조 색상으로 기본 빨강의 광범위한 사용.

### 2.2 전술 텔레메트리 & CRT 터미널
기밀 군사 데이터베이스, 레거시 메인프레임, 항공우주 헤드업 디스플레이(HUD)에서 파생.
*   **특성:** 다크 모드 전용. 고밀도 표 형식 데이터 표현. 고정폭 타이포그래피의 절대적 지배. 기술적 프레이밍 장치(ASCII 괄호, 십자선)의 통합. 시뮬레이션된 하드웨어 제한(인광 글로우, 스캔라인, 낮은 비트 깊이 렌더링) 적용.

## 3. 타이포그래픽 아키텍처
타이포그래피가 주요 구조적 및 장식적 인프라입니다. 이미지는 부차적입니다. 시스템은 스케일, 굵기, 간격에서 극단적인 변이를 요구합니다.

### 3.1 매크로 타이포그래피 (구조적 헤더)
*   **분류:** 네오 그로테스크 / 헤비 산세리프.
*   **최적 웹 폰트:** Neue Haas Grotesk (Black), Inter (Extra Bold/Black), Archivo Black, Roboto Flex (Heavy), Monument Extended.
*   **구현 매개변수:**
    *   **스케일:** 유체 타이포그래피로 거대한 스케일에 배치 (예: `clamp(4rem, 10vw, 15rem)`).
    *   **트래킹 (자간):** 극단적으로 좁게, 종종 음수 (`-0.03em`에서 `-0.06em`), 글리프가 단단한 건축 블록을 형성하도록 강제.
    *   **리딩 (행간):** 높이 압축 (`0.85`에서 `0.95`).
    *   **대소문자:** 구조적 임팩트를 위해 대문자 전용.

### 3.2 마이크로 타이포그래피 (데이터 & 텔레메트리)
*   **분류:** 고정폭 / 테크니컬 산스.
*   **최적 웹 폰트:** JetBrains Mono, IBM Plex Mono, Space Mono, VT323, Courier Prime.
*   **구현 매개변수:**
    *   **스케일:** 고정되고 작게 (`10px`에서 `14px` / `0.7rem`에서 `0.875rem`).
    *   **트래킹:** 넉넉하게 (`0.05em`에서 `0.1em`) 기계식 타자기 간격이나 터미널 매트릭스 시뮬레이션.
    *   **리딩:** 표준에서 좁게 (`1.2`에서 `1.4`).
    *   **대소문자:** 대문자 전용. 모든 메타데이터, 내비게이션, 유닛 ID, 좌표에 사용.

### 3.3 텍스처 대비 (예술적 파괴)
*   **분류:** 고대비 세리프.
*   **최적 웹 폰트:** Playfair Display, EB Garamond, Times New Roman.
*   **구현 매개변수:** 극도로 드물게 사용. 벡터 완벽성을 저하시키고 깨끗한 산세리프와의 텍스처 병치를 생성하기 위해 무거운 후처리(하프톤 필터, 1비트 디더링) 적용 필수.

## 4. 색상 시스템
색상 아키텍처는 타협이 없습니다. 그라데이션, 부드러운 드롭 섀도우, 현대적 반투명은 엄격히 금지됩니다. 색상은 물리적 매체나 원시적 발광 디스플레이를 시뮬레이션합니다.

**중요: 프로젝트당 하나의 기재 팔레트를 선택하고 일관되게 사용하세요. 동일한 인터페이스 내에서 라이트와 다크 기재를 혼합하지 마세요.**

### 스위스 산업 프린트 (라이트)인 경우:
*   **배경:** `#F4F4F0` 또는 `#EAE8E3` (무광, 비표백 문서 용지).
*   **전경:** `#050505`에서 `#111111` (카본 잉크).
*   **강조:** `#E61919` 또는 `#FF2A2A` (항공/위험 레드). 이것이 유일한 강조 색상. 취소선, 두꺼운 구조적 분할선, 중요 데이터 하이라이트에 사용.

### 전술 텔레메트리 (다크)인 경우:
*   **배경:** `#0A0A0A` 또는 `#121212` (비활성 CRT. 순수 `#000000` 피하기).
*   **전경:** `#EAEAEA` (화이트 인광). 기본 텍스트 색상.
*   **강조:** `#E61919` 또는 `#FF2A2A` (항공/위험 레드). 동일한 레드, 동일한 규칙.
*   **터미널 그린 (`#4AF626`):** 선택적. 단일 특정 UI 요소에만 사용 (예: 하나의 상태 표시기나 하나의 데이터 판독) — 일반 텍스트 색상으로 절대 사용 금지. 명확한 목적이 없다면 완전히 생략.

## 5. 레이아웃 & 공간 엔지니어링
레이아웃은 수학적으로 설계된 것처럼 보여야 합니다. 기존 웹 패딩을 거부하고 가시적 구획화를 선호합니다.

*   **청사진 그리드:** CSS Grid 아키텍처의 엄격한 준수. 요소는 떠다니지 않고 그리드 트랙과 교차점에 정밀하게 고정.
*   **가시적 구획화:** 뚜렷한 정보 영역을 구분하기 위한 단색 보더(`1px` 또는 `2px solid`)의 광범위한 사용. 수평선(`<hr>`)이 운영 유닛을 분리하기 위해 전체 컨테이너 너비에 걸쳐 자주 사용.
*   **이중 밀도:** 레이아웃은 극단적 데이터 밀도(밀집된 고정폭 메타데이터가 함께 군집)와 매크로 타이포그래피를 프레이밍하는 광대한 계산된 여백 사이를 진동.
*   **기하학:** `border-radius`의 절대적 거부. 모든 모서리는 기계적 강성을 강제하기 위해 정확히 90도여야 함.

## 6. UI 컴포넌트 & 심볼로지
표준 웹 UI 관례는 실용적이고 산업적인 그래픽 요소로 대체됩니다.

*   **구문 장식:** 데이터 포인트 프레이밍을 위한 ASCII 문자 사용.
    *   *프레이밍:* `[ DELIVERY SYSTEMS ]`, `< RE-IND >`
    *   *방향성:* `>>>`, `///`, `\\\\`
*   **산업 마커:** 법적 텍스트가 아닌 구조적 기하학 요소로 기능하는 등록(`®`), 저작권(`©`), 상표(`™`) 기호의 두드러진 통합.
*   **기술 자산:** 그리드 교차점의 십자선(`+`), 반복되는 수직선(바코드), 두꺼운 수평 경고 스트라이프, 난수 문자열 데이터(예: `REV 2.6`, `UNIT / D-01`)의 통합으로 능동적 기계 프로세스 시뮬레이션.

## 7. 텍스처 & 후처리 효과
디자인이 순수하게 디지털로 보이는 것을 방지하기 위해, CSS와 SVG 필터를 통해 프론트엔드에 시뮬레이션된 아날로그 열화가 설계됩니다.

*   **하프톤 & 1비트 디더링:** 연속 톤 이미지나 큰 세리프 타이포그래피를 도트 매트릭스 패턴으로 변환. 사전 처리 또는 CSS `mix-blend-mode: multiply` 오버레이와 SVG 래디얼 도트 패턴의 조합으로 달성.
*   **CRT 스캔라인:** 터미널 인터페이스의 경우, 수평 전자빔 스위프를 시뮬레이션하는 `repeating-linear-gradient`를 배경에 적용 (예: `repeating-linear-gradient(0deg, transparent, transparent 2px, rgba(0,0,0,0.1) 2px, rgba(0,0,0,0.1) 4px)`).
*   **기계적 노이즈:** 다크 모드와 라이트 모드 모두에서 통합된 물리적 질감을 도입하기 위해 DOM 루트에 적용된 전역 저불투명도 SVG 정적/노이즈 필터.

## 8. 웹 엔지니어링 지침
1.  **그리드 결정론:** `display: grid; gap: 1px;`와 대비되는 부모/자식 배경색을 사용하여 복잡한 보더 선언 없이 수학적으로 완벽하고 매우 얇은 분할선 생성.
2.  **시맨틱 강성:** 텔레메트리의 기술적 특성을 정확히 반영하기 위해 정밀한 시맨틱 태그(`<data>`, `<samp>`, `<kbd>`, `<output>`, `<dl>`)를 사용하여 DOM 구성.
3.  **타이포그래피 클램핑:** 매크로 타이포그래피에 CSS `clamp()` 함수를 독점적으로 구현하여 거대한 텍스트가 뷰포트 전반에 걸쳐 구조적 무결성을 유지하면서 공격적으로 스케일링되도록 보장.
